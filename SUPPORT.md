# Support and questions / 使用与反馈

Start with [local setup](docs/getting-started.md), [troubleshooting](docs/troubleshooting.md) and the [documentation index](docs/README.md).

| Request / 需要什么 | Where / 入口 |
| --- | --- |
| Reproducible bug / 可复现错误 | [Bug report](https://github.com/IntMainJhy/IAVSE/issues/new?template=bug_report.yml) |
| Feature proposal / 功能建议 | [Feature request](https://github.com/IntMainJhy/IAVSE/issues/new?template=feature_request.yml) |
| Learning or usage question / 学习和使用问题 | [Open a question](https://github.com/IntMainJhy/IAVSE/issues/new?title=%5BQuestion%5D%20) |
| Documentation or translation / 文档和翻译 | [Focused pull request](https://github.com/IntMainJhy/IAVSE/pulls) with the affected page and proposed correction |
| Security issue / 安全问题 | Follow [SECURITY.md](SECURITY.md); avoid public exploit details |
| License question / 许可问题 | Read [license guidance](docs/licensing.md) and [LICENSE](LICENSE), then contact the [maintainer](https://github.com/IntMainJhy) for separate permissions |

Include the commit or branch, Node/browser/OS versions, clear reproduction steps and the first relevant error. A small example with disposable data helps more than an entire private environment.

反馈请提供版本、运行环境、复现步骤、期望行为和实际结果。删除真实邮箱、凭据、数据库、简历和用户上传。维护者按可用时间处理，不承诺商业支持、处理期限或上线服务。

If the implementation helps you learn or build, a [Star](https://github.com/IntMainJhy/IAVSE) or an attributed write-up helps other developers discover the project.
