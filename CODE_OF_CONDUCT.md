# Community participation / 参与行为准则

IAVSE welcomes questions, bug reports, documentation, translations and code contributions from people with different experience levels.

参与项目时请：

- 讨论具体问题、代码和行为，尊重不同背景与经验。
- 提供可复现事实，耐心对待新参与者，接受有依据的反馈。
- 保留原作者及第三方署名，分享自己有权提供的材料。
- 尊重隐私，不发送骚扰、威胁、歧视、垃圾广告或他人的私密资料。

In discussions, issues, reviews and pull requests, focus on the work, make room for newcomers, credit sources and protect privacy. Harassment, threats, discrimination, spam and disclosure of another person's private information are not acceptable.

Maintainers may edit or remove inappropriate content, close disruptive conversations or restrict participation using the hosting platform's tools. Decisions should address the conduct and the context.

For a concern about participation, contact the [maintainer](https://github.com/IntMainJhy) through an available private channel. If none is listed, request a contact channel without posting sensitive details. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

This repository participation guide does not replace the independently configured rules for a deployed IAVSE community.
