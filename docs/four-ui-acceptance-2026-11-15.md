# 四套 UI 功能页与手机验收（2026-11-15）

本次沿用已选定的字符潮汐、打开 IAVSE、海风来信和经典原版，不重新设计方向。检查对象是平台页面、导航、外观切换和预览调度，作者正文、画布及模板内容保留自身外观。

## 检查范围

- 手机 390×844：四套样式分别检查社区、资源 Skills 分类、文档、博客目录、登录、账号、空间编辑器、后台、关于、隐私协议、下载、内置模板页，共 48 组路由／样式状态。
- 桌面 1440×900：四套分别检查社区、资源分类、文档、博客目录、账号、编辑器、后台和模板页，共 32 组。
- 补查 320×740、768×1024 和 844×390 的社区、后台及编辑器四项菜单、键盘 End 选择和关闭，共 36 组响应式状态；修正窄屏编辑器后复查四套。
- 实际操作覆盖顶栏和手机底栏导航、连续点击取最后目的地、浏览器前进／后退、外观切换与持久化。检查只使用现有会话，没有编辑、保存或发布作者内容。

## 发现与修复

1. 横屏菜单超出屏幕底部：四项菜单限制为动态视口高度减去顶栏空间，内容在菜单内滚动，键盘可到达最后一项，不增加动画循环或尺寸监听。
2. 320px 编辑器右侧切换按钮及画布工具被挤出视口：窄屏减少顶栏工具间隙，保存按钮采用图标形式，底部画布工具自动换行；保留完整可访问名称和提示、原有语言控件及保存逻辑。
3. 旧博客示例测试未包含新增的共享切换器依赖：修正测试装配，补查普通示例与内置模板均有共享入口，嵌入预览不出现平台控件，预览和完整作品仍使用相同数据。
4. 本地生产预览未明确公开来源，统计 POST 被同源检查拒绝：启动时显式配置与预览一致的 `PUBLIC_URL`。保留原有来源校验，不扩大允许来源或修改实际站点配置。

## 性能观察

在独立生产构建、同一台本机上，四套各采样四次主导航，共 16 次桌面导航；另在手机视口配合 Chromium 4× CPU 节流采样 16 次。时间从真实点击事件到目的路由内容更新，不是完整页面加载或 FPS：

| 观察 | 桌面默认 CPU | 手机视口、4× CPU 节流 |
| --- | --- | --- |
| 四次外观切换的根状态更新 | 6.4–7.1ms | 16.1–19.3ms |
| 16 次导航的内容更新 | 18.7–118.5ms | 75.3–493.8ms |
| 外观切换后两次 RAF 内的观察上限 | 21.9ms | 43.9ms |

桌面采样未观察到超过 50ms 的主线程任务。4× CPU 条件下，首次首页及画廊加载仍出现 50–180ms 的长任务，首个首页内容更新接近 0.5 秒；没有观察到持续挂起或失效的切换控件。样本包含热缓存，没有统一网络节流，也不代表真实低端手机的帧率或严格前后提速对照。

批量 SSR、截图和导航集中运行时曾触发既有 180 次／分钟页面限流；等待窗口后分开执行，没有关闭限流或把 429 页面当作正常 UI 验收。

## 验证结果与边界

全量 741 项单元测试、TypeScript、生产构建及文档检查通过；只读 HTTP 检查通过 60 组路由／样式组合，并覆盖原版深色、非法偏好及权限隔离。构建仍有既有 CSS autoprefixer 兼容提示，没有阻塞构建。

所列功能页未发现横向内容溢出、失败的可见图片或背景画布；所列浏览器流程未发现脚本／水合错误。独立视觉评审检查了代表性手机功能页和菜单，未发现阻塞阅读或主要操作的布局问题；速度判断由主 Agent 的实际操作和采样提供。原始截图及采样保留在公开仓库外，没有纳入提交。

本轮没有运行全部账户写入型 HTTP 套件，没有进行公网部署、数据迁移、SMTP 或实体手机容量测试。此前其他功能的验收范围仍以对应的带日期记录为准。
