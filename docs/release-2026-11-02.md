# IAVSE · 2026-11-02 审计与版本收尾

本次将首页、资源转场和博客空间的已确认改动汇总到 main。所有具名开发分支的提交均已包含在 main 历史中；旧版 UI 的未提交实验不覆盖现有实现，已在仓库外的本地收尾归档中保存补丁、未跟踪文件及 Git 历史 bundle。

## 当前功能

- 深蓝光学玻璃首页与 macOS 下载入口。下载地址来自站点配置；未设置安装包地址时进入下载页面。
- 资源导航预加载、内容转场、返回与取消恢复，以及减少动态效果支持。
- 最多 12 个空间的博客展廊：既有六种排版、八种主题，固定世界位置、拖动视角、点击靠近。真实公开作者优先，静态展示资料不创建账号或计入成员数量。
- 博客卡片使用朝观看方向的轻微倾斜；展廊直接使用站点背景。

## 审计范围与修复

检查了场景生命周期、动画绘制、预览加载队列、键盘/触摸交互、转场恢复，以及公开页、发布、隔离与同源嵌入边界。

1. 相机环顾时缓存卡片变换、可见性与深度样式，跳过未变化的 DOM 写入。
2. 插值改为复用现有数值对象，避免逐帧创建对象与嵌套数组；维持一次统一 O(n) 绘制。
3. 主页加载完成即清理超时定时器；预览仍限两并发，切换保留已加载文档。
4. 作者按钮的方向键从实际聚焦的作者继续移动，避免未选中总览时总从第一项开始。

## 验证与限制

- 385 项单元测试通过，类型检查和生产构建通过。
- 隔离数据库的 homepage HTTP 与 catalog HTTP 套件通过，覆盖已公开快照、私有/受限/下架排除、同源预览、发布权限与 CSRF、目录三种内容及社区关联。
- 本机浏览器复核主分支首页、空间切换与键盘导航；视口检查用于布局与交互验证，不代表所有手机硬件的帧率保证。
- npm 安全公告接口在本次环境中发生 TLS/连接超时，依赖公告扫描未完成。不能把本轮代码审计视为“无依赖漏洞”结论。
- 许可继续采用 PolyForm Noncommercial 1.0.0；第三方许可及网站与私有客户端的范围保持清楚。

## 名称与兼容性

产品及仓库展示名统一为 IAVSE，双语 README、文档导航、品牌说明、仓库介绍与 npm 包元信息同步更新。既有 `spaceyew-*` 服务文件、集成路径、资源文件名、环境变量与私有数据目录是兼容标识，继续有效；无需迁移或重置数据库。历史审计与设计记录保留当时的上下文。
