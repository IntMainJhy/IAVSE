# 平台共享视觉迁移

当前平台沿用用户批准的首页视觉世界：白色空间、黑色功能控件、浮起卡片、艺术字，以及左右两侧自然流动的柔雾。左侧偏青绿，右侧偏浅蓝，两色向中央柔和交叠。共享顶栏保持透明外框与始终可见的毛玻璃导航胶囊，主题按钮紧邻胶囊，品牌与真实账号／头像、语言控件独立放置；功能切换使用滑动镜片与局部文字放大。青绿与浅蓝用于背景和装饰底色，浅色界面的功能主按钮为黑填白字，选中标签、图标、链接和焦点使用中性色；错误、危险操作等既有语义色保留。

这是**共享视觉迁移**：现有页面通过颜色角色、卡片、字段、按钮、排版和平台壳层沿用这一世界，原有搜索、关注、发布、账号、审核和编辑流程继续工作。它不表示每个页面都被重新编写，也不代表逐页视觉验收或完整双 UI 系统已经完成。当前视觉令牌见 [DESIGN.md](../DESIGN.md)，业务、权限与许可边界见 [PRODUCT.md](../PRODUCT.md)。

## 毛玻璃顶栏

顶栏包含左侧 IAVSE 标志／Cormorant 字标、中间的首页／社区／资源／博客空间／关于导航与相邻主题按钮，以及右侧真实 `AuthNav` 账号／头像后面的原 `LanguageSwitcher`。首页与关于入口分别连接已有 `/`、`/about` 页面。整个外框透明、无边框、无阴影；品牌、账号和语言位于导航胶囊之外。1100px 以上使用 `minmax(0,1fr) auto minmax(0,1fr)` 三栏，让导航与主题组合独立居中。

根运行时在首页与合格公共路由之间保留同一顶栏和单个 `GlassSwitch`／镜片 DOM。1100px 及以下使用两行：品牌在左上，账号／头像及语言在右上，同一个常驻导航胶囊与主题按钮居中放在第二行，不再使用汉堡按钮或展开导航。650px 及以下显示精简标签，控件仍保留完整本地化 `aria-label`；可见字号为 12px，360px 及以下为 11.5px。精简标签与文字副本共用实际测量，三种语言不依靠截断来隐藏入口。

首页保留本地背景，并为固定顶栏预留实际高度：1100px 以上 72px、1100px 及以下 122px、650px 及以下 110px。外框内边距依次为 8px 0、6px 0、4px 0；顶部距离为 20px，650px 及以下为 12px。非首页的 `PublicFrame` 公共路由分别追加 52px／48px 的紧凑顶栏避让；该规则不施加到首页、作者内容或独立工作台。顶栏宽度上限为 1120px，1500px 起为 1240px；页面侧边距默认 40px、900px 及以下 24px、650px 及以下 16px。作者页面、预览、博客编辑器与管理端的既有边界保留。

导航胶囊使用半透明渐变、24px 模糊、1.12 饱和度、细边和边缘阴影，内边距为 6px，650px 及以下为 4px。浅色使用白色玻璃；深色顶栏底槽为中性 `rgb(32 32 38 / .5)` → `rgb(24 24 30 / .3)` 渐变，边线为白色 .18，保留背景透出与磨砂层次。深色固定顶栏在模糊后将背板亮度限制为 .36，再叠加底色和镜片，避免滚过明亮封面时浅色文字失去对比度。深色主题、语言与账号控件底片采用相同亮度保护及 18px 模糊；不支持模糊时使用顶栏面板底色。其他深色 GlassSwitch 底槽使用白色 .055 → .02 渐变、白色 .12 边线和 16px 模糊。选中镜片独立使用较亮的白色 .19 → .055 渐变、.28 高光边、.38 顶部内高光、底部内阴影及 10px 模糊，避免底槽与镜片合成一块不透明深色。首页背景、卡片、筛选、正文和动作同样具有局部深色角色，柔雾叠加在深色画布上。这些角色不替换全站应用色板。标准与 WebKit 背景模糊路径保持一致；两者均不支持时，深色通用底槽使用 `#27272d`、镜片使用 `#414147`，导航胶囊使用当前外观的面板底，外框仍透明。

主题按钮读取实际文档的 `data-color-mode`，更新模式、偏好和原有一年有效的 `site-color-mode` cookie，沿用公开 Portfolio 的 700ms 圆形 View Transition 契约，并从按钮位置展开。减少动态或缺少 API 时直接切换。意图与代次保护保留过渡提交前的连续点击结果，已有来源注释与许可归属保留。语言菜单仍使用原组件；首页页脚不再重复语言入口。

真实账号头像使用自己的圆形裁切盒与 `object-fit: cover`，不依赖某个功能页的头像样式包。实际登录／注册表单保留在各自最大 480px／560px 的白卡中，卡片内边距 34px，手机变为 28px 22px；表单网格子项保持全宽后再居中，避免窄屏挤成多栏。

## 当前首页组合

首页开场至少占满一个动态视口。标题与简介居中，简介下方的液态玻璃胶囊包含「社区」和「资源」两个链接，分别通往 `/community` 和 `/resources`。两个链接等宽，静止时均未选中。鼠标悬停、键盘聚焦或触摸按下时，透镜移向目标并放大经过的文字。按下时透镜略微收缩、变暗，松开即回弹。在减少动态模式下仅保留明暗反馈。点击或按回车可进入目标页面。较矮的视口会优先为固定顶栏留足空间。向下滚动后依次显示社区动态、四类资源、个人主页与空间预览和页脚。旧的资源侧栏及横向空间卡片属于此前首页表达，不是当前布局。

内容仍使用原有权限校验后的公开 DTO：最多四条帖子、来自最多四个可发现公开空间的三项作品。发现展示首项作品或帖子及可用讨论，作品与讨论筛选展示各自有界列表；无内容、暂时不可用及刷新重试均对应真实状态。资源索引分别连接 `/resources?type=designs`、`skills`、`docs`、`resources`，并提示在详情查看来源与许可。个人主页说明连接真实编辑器和 `/blogs`，解释现有手动发布／文章审核规则。空间卡使用实际公开成员的封面或圆形头像；无成员时保留“内置模板预览 · 虚构人物”标签及目录入口。

首页正文最大宽度为 1000px，视口宽度达到 1500px 时上限为 1080px。侧边距依次为默认 40px、1000px 及以下 24px、740px 及以下 20px、380px 及以下 16px。740px 及以下，社区与个人主页组合改为单列；资源索引仍为两列。中文主标题分两行，桌面字号在 35–48px 间变化，740px 及以下为 28–36px。社区空状态卡片最小高度分别为 160px 与 146px。白色浮起卡片、原有入场、指针响应和减少动态降级保留。这次调整未增加媒体、依赖、私有材料或成员数据。

## 滑动镜片与局部文字放大

当前 `GlassSwitch` 用在四处：共享顶栏、首页内容类型筛选、资源类型导航和社区“全部动态／正在关注”切换。资源查询、关注权限和真实目的地沿用原逻辑。

镜片由原生 DOM 与 CSS 构成：

1. 原本的链接或按钮保持唯一的交互入口。链接使用实际 `href` 和当前路由的 `aria-current`；按钮使用 `aria-pressed` 与原生禁用状态。
2. 组件测量每个控件的实际位置、尺寸，并在一层 `aria-hidden`、`inert`、不响应指针的轨道中放置文字副本。这些副本不增加可聚焦项或读屏标签。
3. 镜片按选中项尺寸滑动并裁切副本；内部整条副本轨道做等量反向平移，使文字保持与原位置对齐，再以镜片中心作局部缩放。
4. 位移采用 cubic ease-out，按测量距离累计约 390–540ms 的有效动画帧运动时间：从首个实际送达的动画帧开始，后续单帧间隔最多计入 50ms。繁忙路由可能延长墙钟完成时间，但长任务间隔不会一次耗尽可见行程。放大发生在经过过程中，最高 1.15 倍，落定后回到 1 倍。镜片自身在浅色下使用 7px、深色下使用 10px 背景模糊，并保留独立高光边与阴影层次。
5. 字体完成加载、窗口或控件尺寸变化、语言与精简标签变化后重新测量。目标位置／尺寸未变的观察器或字体通知不会取消正在进行的动画；实际几何变化会从当前视觉位置继续转向新目标，避免滑动中途吸附。
6. 普通链接点击可立即显示短暂的镜片意图响应；`aria-current` 继续描述真实路由，不能提前伪造当前页面。真实选中值变化时清除该意图与计时器，浏览器后退不会重新触发旧点击；点击当前项同样清除意图。修饰键／新窗口操作保留原生行为。

这是一种**局部文字放大与玻璃材质处理**，不是物理折射模拟，没有光线追踪、3D 玻璃模型或背景光学求解。未测得镜片时，选中控件自带当前外观的选中底；减少动态效果时直接定位，取消移动与放大脉冲。页面隐藏时镜片结算到目标位置，并在卸载时取消动画、观察器和监听。

## 柔雾、卡片与入场动效

两侧雾团以不同相位流动，混色区随时间和水平手势轻微偏移。共享雾层在桌面与手机上均为一屏可见视口高，顶部约 100px 透明。首页将雾层放在顶部介绍区，在底部淡出，之后的社区动态、资源目录与个人博客区使用页面底色。静态回退通过两层半透明渐变形成混色。鼠标划过或手指轻触时，局部青绿和浅蓝交融，触摸滚动和控件点击沿用原生行为。背景离屏或标签页隐藏时暂停，减少动态效果时为静态帧。机制、性能与限制见[背景说明](purple-landing-background.zh-CN.md)。

首页卡片悬停抬升 6px，功能资源／设计／Skill 卡片抬升 4px；白色卡片和细阴影统一层次，保留内容自身的图像与颜色。首页 Scroll Reveal 使用 24px 上移淡入、650ms、0.1 交叉阈值，空状态卡片也进入这一既有序列；既有应用入场使用 12px、550ms、0.12 阈值和 `0px 0px -6% 0px` 根边距，保留模板 FadeIn 的 800ms。博客产品介绍通过 scope／group／item 标记明确接入 21 个短小可读内容块；同一观察器批次内按位置排序，各语义分组重新从首项计算 70ms 交错延迟，最多 210ms。顶栏、画廊、静态示意图及完整的长章节不参与此入场，作者内容也不在处理范围。首页、应用和滚动型 FadeIn 在元素完整离开物理视口后，再从上方或下方进入时重播；仍可见时跨越入场阈值或根边距不会重新隐藏或重播。显式 mount FadeIn 与 ScaleUnblur 保留挂载入场。键盘进入待显示内容会立即显现，焦点停留期间保持可读；减少动态效果会取消入场、悬停位移与镜片缩放并显示所有内容，缺少观察或动画 API 时保持可读，路由／查询变化清理动画和观察器。

## 验收与交付边界

- 检查桌面与手机的两侧雾团的混色、中央文字可读性、导航／账号和三种语言换行；正常动态、减少动态、WebGL／模糊降级、键盘焦点都属于视觉验收范围。

## 社区信息流与手机底栏

社区保留“全部动态／正在关注”的真实视图，参考 [X 的时间线分区](https://help.x.com/en/using-x/x-timeline)收紧信息层级。时间线采用白色内容纸面和细分隔行；首页、目录等页面继续使用浮起卡片。空状态在时间线内提供真实投稿入口。

搜索改为常驻输入框和明确提交按钮，通过 GET 保留 `q`、`category`、`feed`；原生分类选择可直接提交。当前输入不会生成推荐或模拟结果。实现见 [CommunityApp](../src/components/CommunityApp.tsx) 和[社区专属样式](../src/app/community-timeline.css)。

手机底栏按当前可见目的地分成访客三项、已登录五项。装饰透镜采用绝对定位，不再参与排列；[导航定位逻辑](../src/components/useLiquidCommunityNav.ts)只测量可见目标，并把“关注动态”映射到社区入口。底栏自身高度与安全区、浮动投稿按钮、弹层和正文底部留白共用一组变量。相同修正同时加载在社区及成员工作区，原生焦点、真实链接和减少动态偏好保留。
