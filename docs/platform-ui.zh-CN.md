# 平台共享视觉迁移

当前平台沿用用户批准的首页视觉世界：白色空间、黑色功能控件、浮起卡片、艺术字，以及左右两侧自然流动、中央留白的紫色柔雾。共享顶栏仅中央导航胶囊采用毛玻璃，品牌与账号在两侧独立放置；功能切换使用滑动镜片与局部文字放大。紫色只承担背景和装饰底色，浅色界面的功能主按钮为黑填白字，选中标签、图标、链接和焦点使用中性色；错误、危险操作等既有语义色保留。

这是**共享视觉迁移**：现有页面通过颜色角色、卡片、字段、按钮、排版和平台壳层沿用这一世界，原有搜索、关注、发布、账号、审核和编辑流程继续工作。它不表示每个页面都被重新编写，也不代表逐页视觉验收或完整双 UI 系统已经完成。当前视觉令牌见 [DESIGN.md](../DESIGN.md)，业务、权限与许可边界见 [PRODUCT.md](../PRODUCT.md)。

## 毛玻璃顶栏

顶栏分为三部分：左侧 IAVSE 标志／Cormorant 字标、正中的社区／资源／博客空间导航，以及右侧真实 `AuthNav` 账号状态。品牌与登录／头像位于导航胶囊之外。整个外框透明、无边框、无阴影，使用 `minmax(0,1fr) auto minmax(0,1fr)` 三栏，让中央导航独立居中，不受左右区域宽度差异影响。

只有中央桌面导航胶囊及手机的小菜单触发胶囊采用白色半透明渐变、24px 模糊、1.12 饱和度、细白边和边缘阴影。桌面胶囊内边距为 6px；外框不再把品牌和账号包进同一玻璃面。当前导航胶囊显式采用浅色表现；功能页暗色偏好使用相应中性色角色，柔雾在暗色壳层中降低强度。

桌面外框最小高度 70px、内边距 8px 0，距顶部 20px；650px 及以下变为 62px、内边距 7px 0，距顶部 12px。820px 及以下由中央独立的小胶囊展开原生 `details` 手机菜单，品牌和账号仍分居两侧，三种语言的菜单标签可以平衡换行。点击外部、离开菜单焦点、切换路由／语言或按 Escape 都会关闭菜单；Escape 返回触发器焦点。没有背景模糊支持时，仅导航胶囊／菜单改用更实的白色底，外框保持透明。

真实账号头像使用自己的圆形裁切盒与 `object-fit: cover`，不依赖某个功能页的头像样式包。实际登录／注册表单保留在各自最大 480px／560px 的白卡中，卡片内边距 34px，手机变为 28px 22px；表单网格子项保持全宽后再居中，避免窄屏挤成多栏。

## 滑动镜片与局部文字放大

当前 `GlassSwitch` 用在四处：共享顶栏、首页内容类型筛选、资源类型导航和社区“全部动态／正在关注”切换。资源查询、关注权限和真实目的地沿用原逻辑。

镜片由原生 DOM 与 CSS 构成：

1. 原本的链接或按钮保持唯一的交互入口。链接使用实际 `href` 和当前路由的 `aria-current`；按钮使用 `aria-pressed` 与原生禁用状态。
2. 组件测量每个控件的实际位置、尺寸，并在一层 `aria-hidden`、`inert`、不响应指针的轨道中放置文字副本。这些副本不增加可聚焦项或读屏标签。
3. 镜片按选中项尺寸滑动并裁切副本；内部整条副本轨道做等量反向平移，使文字保持与原位置对齐，再以镜片中心作局部缩放。
4. 位移采用 cubic ease-out，按测量距离累计约 390–540ms 的有效动画帧运动时间：从首个实际送达的动画帧开始，后续单帧间隔最多计入 50ms。繁忙路由可能延长墙钟完成时间，但长任务间隔不会一次耗尽可见行程。放大发生在经过过程中，最高 1.15 倍，落定后回到 1 倍。镜片自身有 7px 背景模糊、白色高光边和浅阴影。
5. 字体完成加载、窗口或控件尺寸变化、语言变化和手机换行后重新测量。目标位置／尺寸未变的观察器或字体通知不会取消正在进行的动画；实际几何变化会从当前视觉位置继续转向新目标，避免滑动中途吸附。
6. 普通链接点击可立即显示短暂的镜片意图响应；`aria-current` 继续描述真实路由，不能提前伪造当前页面。真实选中值变化时清除该意图与计时器，浏览器后退不会重新触发旧点击；点击当前项同样清除意图。修饰键／新窗口操作保留原生行为。

这是一种**局部文字放大与玻璃材质处理**，不是物理折射模拟，没有光线追踪、3D 玻璃模型或背景光学求解。未测得镜片时，选中控件自带白色选中底；减少动态效果时直接定位，取消移动与放大脉冲。页面隐藏时镜片结算到目标位置，并在卸载时取消动画、观察器和监听。

## 柔雾、卡片与入场动效

背景保持左右独立的软锚定雾域、中央白色及顶部约 100px 的净白，不用高对比条带替代雾团。当前着色器采用 `uTime * 0.12`；静态降级同样保留左右两片浅紫与中央白色。细鼠标可轻微影响局部形态，触摸设备保留自动流动和原生滚动。背景离屏或标签页隐藏时暂停，减少动态效果时为静态帧。机制、性能与限制见[背景说明](purple-landing-background.zh-CN.md)。

首页卡片悬停抬升 6px，功能资源／设计／Skill 卡片抬升 4px；白色卡片和细阴影统一层次，保留内容自身的图像与颜色。首页 Scroll Reveal 使用 24px 上移淡入、650ms、0.1 交叉阈值；既有应用入场使用 12px、550ms、0.12 阈值和 `0px 0px -6% 0px` 根边距，保留模板 FadeIn 的 800ms。分组每项延迟 70ms，最多 210ms。键盘进入待显示内容会立即显现，减少动态效果会取消入场、悬停位移与镜片缩放。

## 验收与交付边界

- 检查桌面与手机的双侧雾团、中央留白、导航／账号和三种语言换行；正常动态、减少动态、WebGL／模糊降级、键盘焦点都属于视觉验收范围。
- 检查链接路由和筛选查询、社区关注、真实空态、账号权限及工作台操作；外观变化不能替代行为验证。
- 检查作者博客、内置模板、设计预览与画布仍保留自身样式；管理端和编辑器没有重复公共顶栏。
- 本页记录实现边界，不复用旧首页的测试数字，也不宣称每个页面已逐一验收。运行测试、类型检查、生产构建和最终浏览器检查以本轮实施结果为准。
- 本机验收截图、真实上传、数据库、环境文件、私有 Pro 内容及只读参考材料不进入公开仓库；不因为视觉迁移扩大许可或声明正式部署。

## 社区信息流与手机底栏

社区保留“全部动态／正在关注”的真实视图，参考 [X 的时间线分区](https://help.x.com/en/using-x/x-timeline)收紧信息层级。时间线采用白色内容纸面和细分隔行；首页、目录等页面继续使用浮起卡片。空状态在时间线内提供真实投稿入口。

搜索改为常驻输入框和明确提交按钮，通过 GET 保留 `q`、`category`、`feed`；原生分类选择可直接提交。当前输入不会生成推荐或模拟结果。实现见 [CommunityApp](../src/components/CommunityApp.tsx) 和[社区专属样式](../src/app/community-timeline.css)。

手机底栏按当前可见目的地分成访客三项、已登录五项。装饰透镜采用绝对定位，不再参与排列；[导航定位逻辑](../src/components/useLiquidCommunityNav.ts)只测量可见目标，并把“关注动态”映射到社区入口。底栏自身高度与安全区、浮动投稿按钮、弹层和正文底部留白共用一组变量。相同修正同时加载在社区及成员工作区，原生焦点、真实链接和减少动态偏好保留。
