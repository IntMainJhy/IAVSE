## 展示与范围

- 首页保留原首屏玻璃 3D、使命文字、真实创作者展台、原生纵向滚动。导航背层及活动下划线关闭，当前项以字重表达，焦点轮廓保留；标识仍为统一 28px。复用原 PlatformGlass 被动滚动监听，在首页渐变进入浅色时切为深字，不增加绘制循环或布局读取。
- 评价区从双排彩色自动跑马灯改为单排白银卡片画廊。保留六条三语示例内容、作者与头像，以及“示例评论”声明。原生触摸／横向滚动、44px 前后按钮与左右／Home／End 键可用，纵向手势不拦截；没有自动滚动或克隆，减少动态时直接静态。
- 社区使用清晰大标题、简洁动态范围、内容面板与紧凑搜索，提供实际白银／中性深灰主题；手机液态导航的功能和几何保留。
- 资源、Skill、文档保留通栏分类、搜索、真实数据及 Bento 跨度，统一字阶、留白、24px 视觉圆角和轻影。法律咨询保留真实照片、资质与联系资料，改为白／深灰信息面板与蓝色操作。
- `/blogs` 改为白色基础、银灰内容舞台、居中标题和蓝色入口；保留 3D 主页预览的选择、拖拽、完整 SSR 目录及真实链接。装饰性 QuantumBackdrop 在此路由退出；原电影区编辑舞台图片背景撤下，孤立的 studio-light 图片与来源 sidecar 删除。社区／资源／空间的装饰指针不再叠在信息和菜单上；原首页开场及其他既有区域行为保留。

## 清透明导航

非首页平台顶栏使用薄而清晰的材质：白色 .12 / 深色 .22 底色，8px backdrop blur 与 1.1 saturate，仅作用于自身 `::before` 背层；文本和菜单不经过滤镜。没有大面积灰白遮罩、额外尾部渐变或持续效果循环。减少透明度／无滤镜支持时仍回退实色。空间页为用户要求的局部浅色，透明栏文字也按该实际背景保持深色。

## 网站公告与后台

后台入口为 **网站设置 → 网站公告**。独立保存开关、最多三条公告、每条最多 120 字和可选跳转链接。可增删条目、查看未保存状态、保存／失败／重试；关闭不丢弃后台已编辑内容。公告使用独立 config key `announcements`，不会覆盖网站资料、下载或密码表单。

公共 `GET /api/announcements` 仅重建展示所需字段；关闭时返回空 items，损坏配置不公开。后台 GET／POST 使用原 owner 权限、Origin／CSRF、事务和审计机制。只允许安全站内路径或 HTTPS 链接，拒绝协议相对、反斜杠、控制字符、凭据和危险协议。首次保存专用 UPSERT，避免不存在的配置被旧 UPDATE 静默丢失。

公告初始数据从根服务端布局读取并注入 Provider，HTML 初始占位状态与首次内容一致，不在 hydration 后突然撑高。公告占用稳定 44px 行；PublicFrame 内容增加对应占位，博客平台栏自然扩高，后台保留 64px 操作行并增加独立公告行，画布在 flex 布局内预留高度。登录管理页也展示公告。Home 与画廊嵌入／作者画布预览不放公告。

保存事件触发本标签刷新，并通过 BroadcastChannel 通知同源标签页；无持续轮询或自动跑马灯。新服务器 initial prop 在布局阶段同步并中止旧请求，避免 RSC／语言刷新后的内容与占位不一致。请求失败保留上次完整公告，卸载中止请求并清理事件和通道。长纯文字公告也有可聚焦原生横向区域；窄屏隐藏重复视觉标签，语义标签保留。

公告高度也计入法律联系、空间产品标题等锚点留白，以及编辑器发布面板相对根节点的定位。
