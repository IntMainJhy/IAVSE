## 统一规范

`site-chrome.css` 从根 layout 导入，避免路由切换后共享样式缺失。PublicFrame、BlogPublic 平台栏、后台操作条分别使用 `data-site-chrome=public/blog/admin`，既有品牌链接使用 `data-site-brand`。共享几何和材质声明采用明确的 `!important` 所有权，压住历史页皮肤，不依赖路由 CSS 到达次序。

所有四处既有品牌标识统一为 28×28px，intrinsic width/height 与 flex-basis 同为 28px；原蓝色图形保留，取消尺寸分歧、滤色和圆角。字标桌面 22px、手机 20px，字重 500、字距 .1em。320px 也显示完整 IAVSE，不再随路由隐藏。

公共与独立博客平台栏内层桌面 72px、水平 32px，767px 以下 64px / 20px。窄博客沿用两行功能布局，避免压缩社区名片与分享按钮。后台保留 64px 操作条、侧栏和手机抽屉结构，仅共享材质与既有品牌规范。画布编辑器自己的工作流工具条保留既有中性玻璃、返回网站和编辑操作，不增加 Logo。作者自定义页头、画布内容、嵌入上传站点均不匹配新规则。

## 玻璃与主题

顶栏本身透明，不设置 backdrop-filter；仅 `::before` 背层占自身 100% 高度，使用 `blur(16px) saturate(1.05)`、`pointer-events:none`，在 isolation 内置于内容后方。文字与菜单不经过滤镜，也不会给 fixed 弹层添加滤镜包含块。旧 144px 渐变模糊尾和第二装饰层关闭。

浅色白色透明度 .58、深色 #1d1d1f 透明度 .68，文字分别 #1d1d1f / #f5f5f7，底部细分隔线。品牌与导航文字不再继承旧 .65s 颜色过渡，主题背景和前景同步，保留轻量透明度反馈。减少动态时关闭该反馈。开启减少透明度或浏览器不支持 backdrop-filter 时，回退 #fafafa / #1d1d1f 实色；打印关闭材质。没有新增运行时监听、绘制循环、字体或图片请求。
