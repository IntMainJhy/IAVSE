## 发布规则

| 类型 | 保存 | 公开 |
| --- | --- | --- |
| 普通成员个人主页 | 私有草稿，与公开快照分离 | 作者显式发布，不要求先审核；可关闭目录发现或下线 |
| 作品、资源 | 私有草稿 | 按账号资格显式发布 |
| 博客文章、文档 | 私有草稿 | 提交固定版本审核，通过后公开 |
| 社区分享 | 私有草稿 | 自动模式中普通原创文字经检查直接公开；外链、图片、来源或风险命中等转复核；手动模式仍逐帖审核 |
| 评论 | 服务端权限和内容检查 | 依当前规则直接发表，保留举报、限制与下线能力 |
| 自动采集资源候选 | 私有待审记录 | 来源、许可和内容核验后由站长明确发布 |

站长对自己内容的既有保存例外见[博客编辑指南](blog-editor.zh-CN.md)。冻结、资格、规则确认、版本冲突检查仍在服务端执行。`siteOwnerAccount` 是公开作者标识，不授予管理权限；`ownerAccount` 才是唯一站长绑定。客户端不决定这些权限。

## 尚未完成的交付

- **目标生产环境验收**：正式域名、HTTPS／代理、管理子域、Cookie、SMTP 实际投递、备份调度与告警、外部下载链接、真实流量与容量均需部署后验证。本次未部署或开放公网。
- **身份核验闭环**：当前代码可记录已完成的人工核验；没有接入真实身份核验服务。当前 `publishingQualified` 也接受有效规则确认状态，不能把应用内规则勾选或本机测试当作真实身份核验。生产开放条件及运营安排见[公开运营说明](public-launch.md)。
- **运营处置**：自动检查是分流，不是对全部违法或侵权内容的识别保证。管理员仍需处理风险队列、举报、申诉和紧急下线；本次不作“已经全面合规”的结论。
- **容量边界**：本轮上传实测 64 MiB，包含服务重启续传；没有重新实测 10 GB，也没有进行生产并发压力测试。
- **外部工具与自动任务**：本轮验证了 IAVSE 接口、范围授权和本地桥接逻辑，未重新接入外部 AI 客户端或申请 uiX 素材，也未安装或实测生产采集定时服务。
- **Pro 与桌面客户端**：Pro 私有 UI、素材授权交付、独立构建入口及客户端安装包不在本轮网站验收范围。公开 UI 的迭代不等于双 UI 计划全部完成。见[双 UI 阶段表](dual-ui-task-board.md)。
