# 资源目录的统一布局

更新：2026-11-13。[视觉规范](../DESIGN.md) · [验收记录](acceptance-2026-11-13.md)

所有资源类型沿用同一宽度、搜索与筛选语言，区别只在各目录实际支持的维度，不把全部选项堆成多排大胶囊。

- `ResourceHub` 统一资源导航；UI 设计、文档、Skill、网站与工具分别保留自己的查询参数、内容和发布入口。
- `DirectorySearch` 负责搜索展开、显式提交、`/` 聚焦、Esc 取消、清空及查询上下文；关闭后输入不可聚焦。
- `DirectoryFacet` 负责工具、用途、行业、风格、分类及排序等独立维度。至少 42px 控件（手机 44px）保持紧凑，选中摘要清晰；弹层条目之间保留 4px 间距、7px 圆角，只有当前项填充，长文字换行而不重叠。
- 菜单支持点击外部与 Esc 关闭；靠近视口底部时向上展开，手机避让固定底栏。菜单不套用导航镜片或大胶囊样式。
- 共用规则在 `directory-toolbar.css` 的 `@layer rbp`，旧的 important 规则存在时必须理解层顺序，不能用无层全局覆盖造成反向优先级问题。
- UI 目录卡片以大幅预览为主要内容，桌面按可用宽度分栏，手机单列；不通过缩小整页塞入更多卡片。Skill 仍为每页 36 项，保留真实仓库、类型、技术标签、详情和安装入口，不生成虚构预览。
- 空结果、收藏、排序与分页均保留；筛选显示文案可翻译，提交值仍为原始稳定分类值。深色、减少动态与键盘焦点跟随共享系统。

2026-11-08 的旧版下划线工具栏和大圆角筛选已由上述控件替代。其历史 660 项测试只属于当日记录；当前结果见收尾验收。
