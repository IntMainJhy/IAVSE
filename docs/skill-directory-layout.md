# 资源目录的统一布局

更新：2026-11-15。[视觉规范](../DESIGN.md) · [验收记录](acceptance-2026-11-13.md)

所有资源类型沿用同一宽度、搜索与筛选语言，区别只在各目录实际支持的维度。筛选选项按用户要求直接展示，按维度分行排列，手机自动换行；不再折叠或弹出菜单。

- `ResourceHub` 统一资源导航，栏目使用直接链接，移除外围边框、底色和阴影，仅当前栏目保留浅色高亮；UI 设计、文档、Skill、网站与工具分别保留自己的查询参数、内容和发布入口。
- `DirectorySearch` 负责搜索展开、显式提交、`/` 聚焦、Esc 取消、清空及查询上下文；关闭后输入不可聚焦。
- `DirectoryFacet` 直接展示工具、用途、行业、风格、分类及排序等独立维度。各组选项保持原有链接或按钮与计数，当前项高亮，长文字正常换行；手机选项至少 44px 高。
- UI 设计的用途、行业和视觉筛选不再受“筛选”按钮控制；文档、Skill、网站工具和社区分类采用相同的常显方式。社区手机端的搜索输入仍可单独展开，分类始终可见，搜索保留当前分类。
- 筛选组使用原生按钮/链接与 `role=group`，保留 `aria-pressed` 或 `aria-current`、键盘焦点和查询参数；不再注册菜单定位、点击外部关闭及 Escape 关闭监听。只读筛选与搜索不影响内容表单和权限。
- 共用规则在 `directory-toolbar.css` 的 `@layer rbp`，旧的 important 规则存在时必须理解层顺序，不能用无层全局覆盖造成反向优先级问题。
- UI 目录采用宽幅交错瀑布流，取消固定内容最大宽度：1600px 及以上三列，901–1599px 两列，900px 及以下单列，以大图为主。图片保持原始比例完整等比显示，不裁切、拉伸或悬停放大；通过不同列的起点形成错位。标题位于图片下沿，收藏位于右上角；图片外不显示标题、类型、许可或描述。点击图片打开预览，点击图内标题查看完整说明、分类、技术栈、许可及来源。
- 四套全站 UI 共用同一画廊结构，预览图片保持原作品颜色。瀑布流沿用 DOM 与键盘顺序，一个网格尺寸观察器批量测量封面并写入行跨度，追加条目不重新平衡已经浏览的列；无脚本时仍可按普通网格阅读。目录继续使用静态封面、懒加载、每批 24 项和一个按需预览弹窗。Skill 仍为每页 36 项，保留真实仓库、类型、技术标签、详情和安装入口，不生成虚构预览。
- 图内操作、该目录的公共顶栏、分类与筛选条采用无白色填充的透明磨砂玻璃；GitHub 不带箭头。文字和图标在图片上适配明暗，图片本身保持原色。
- 空结果、收藏、排序与分页均保留；筛选显示文案可翻译，提交值仍为原始稳定分类值。深色、减少动态与键盘焦点跟随共享系统。

2026-11-08 的旧版下划线工具栏和大圆角筛选已由上述控件替代。其历史 660 项测试只属于当日记录；当前结果见收尾验收。

2026-11-15 常显筛选更新：63 项相关单元测试、类型检查、隔离生产构建、文档检查和 10 项目录 HTTP 检查通过。浏览器检查四套 UI 的设计目录在 1640/390/320px 的显示，以及文档、Skill、网站工具、社区的桌面和手机布局；修正 Skill 旧样式强制不换行导致的手机宽度溢出，并在 390/320px 生产页面复核。实际点选设计分类及行业、Skill 工具与类型组合、社区分类与搜索，刷新后查询和选中反馈保持。未运行全量测试或部署。
