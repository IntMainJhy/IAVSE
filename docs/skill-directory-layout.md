# Skills 与 UI 目录的共同布局

2026-11-08：修复资源子导航在 UI 与 Skill 之间切换时横向位移的问题，并统一目录控件与卡片视觉。

- `resource-frame.css` 统一带资源类型导航的公共主容器：最大 1840px，桌面两侧 32px，820px 以下两侧 20px。目录和直接访问的 `/skills`、`/docs` 使用同一导航起点；无此导航的详情页保持阅读宽度。
- UI 与 Skills 共用 `DirectorySearch`：按钮展开、显式提交、`/` 聚焦、Esc 取消未提交输入并收起、清空搜索、关闭时不可聚焦。Skills 搜索继续保留类型、工具与来源集合，原生 GET 字段也保留这些条件。
- Skills 使用 UI 的网格、20px 圆角、阴影、悬停、玻璃渐变与底部操作栏。顶部 GitHub 按钮链接真实仓库，分类和技术标签取自原目录数据，不生成虚构网站封面。卡片说明两行省略，完整内容仍可进入详情查看。
- AI 工具采用下划线导航，Skill 类型采用圆角筛选。按任务推荐保留在可展开区域。安装入口、来源与许可入口、原有每页 36 项和分页逻辑保留。
- `skill-explorer.css` 仅为 Skills 目录补齐适配；颜色跟随明暗主题，覆盖旧阅读样式中的固定链接颜色。详情页没有套用卡片样式。

验证：660 项单元测试、类型检查；浏览器检查 1453px 桌面、390px 窄屏、明暗主题、跨目录导航、提交/取消/清空搜索、工具与类型筛选、详情的安装和返回上下文。桌面导航与搜索按钮在两目录的坐标一致，36 张卡片高度一致，窄屏无横向溢出。Skills HTTP 验证覆盖 72 个详情页、15 个工具列表、6 个目录页及中英日语言。生产构建通过，UI 模板 HTTP 验证通过 194 项检查（包含 108 个规范变体、66 张静态封面及空闲状态零 iframe）。生产验证按站点请求窗口节流执行，没有修改限流规则。
