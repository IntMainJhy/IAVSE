# 导航与动态场景检查（2026-11-15）

已检查三套 UI 的普通导航、资源目录与详情、浏览器前进后退、手机底部导航、快速连续点击、场景切换、离屏暂停和减少动态偏好。

## 修复

原有 NavigationIntent 只识别旧的 organic-header，新 IAVSE 导航没有接入意图预加载。现在识别共享页头的导航与标志、手机底部导航，并覆盖包括“关于”在内的五个公开目的地。悬停 120ms、键盘聚焦或触摸时准备当前目标；扫过、修饰键、站外链接、下载、慢速网络和省流偏好沿用保护。导航链接关闭视口内自动预取，避免打开页面就同时加载多个未选择的目的地。点击与未保存草稿保护仍由原控制器处理。

## 验证

- TypeScript 与 81 项相关测试通过，覆盖意图预加载、页面转场、快速打断、回退、未保存确认、玻璃导航和全站样式。
- 在仓库外复制源码，使用隔离数据目录完成 Next.js 生产构建和本地启动，保留原开发服务器。构建通过；存在既有 CSS 的 autoprefixer start/end 兼容性提示，不影响构建。
- 生产模式 15 条路由 × 3 套样式的只读 HTTP 检查通过。
- 真实浏览器验证新的悬停预加载确实产生对应的 RSC 请求；该次请求约 44ms。
- 三套 UI 各完成手机底部四个目的地的往返；资源目录到 React Best Practices 详情、Back/Forward、桌面与手机快速连续点击通过。选择保持一致，无遗留 busy 状态、横向溢出或脚本错误。
- 本机正常点击到路由内容更新的样本约 10–70ms；该数值不包含全部入场动画完成时间，也不代表公网网络延迟。
- 三套首页分别采集桌面与 390×844、4 倍 CPU 降速样本，持续采样阶段无 50ms 以上主线程长任务。动画回调工作 P95：桌面约 0.2–0.5ms，降速样本约 0.5–1.1ms。测试探针统计的是 RAF 回调和绘制提交，不将其当作屏幕实际呈现帧率。
- 字符场景滚出首屏后绘制计数归零；15 次 UI 连续切换后仅保留一个场景和画布，无 WebGL 上下文警告。
- 系统减少动态偏好启用后，首页暂停；恢复普通偏好后继续运行。

原始指标和截图保存在公开仓库之外。生产检查使用本地隔离数据与匿名界面；手机尺寸和 CPU 降速是模拟检查，未宣称真机 GPU 或线上容量测试。未正式部署。
