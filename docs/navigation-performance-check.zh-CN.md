# 导航与动态场景检查（2026-11-15）

本轮同时简化三套首页，并针对顶栏首次切换、资源分类与快速连续点击进行优化。

最后一轮跨页、手机和平板复查、两处响应式修复及默认／4× CPU 采样见[四套 UI 收尾验收](four-ui-acceptance-2026-11-15.md)。本机生产预览需显式设置与实际端口一致的 `PUBLIC_URL`，使统计等 POST 正常通过既有同源检查。

## 四套 UI 整合后的补充优化

- 恢复 `main@97871e0` 的原版首屏、雾光和浅／深色，作为第四个全站选项。原版着色器通过独立 lazy import 加载，切换其他样式不执行它的初始化。
- 功能页的背景改为静态插画或 CSS 柔雾；品牌版直接移除右上角大字标。功能页不再创建背景画布、动画循环和对应的可见性监听，首页仍保留动态效果。
- 原生顶栏和手机导航的 `useLinkStatus` 接入既有导航工作门控；请求未完成时暂停画廊相机和可选预览工作。重叠请求以独立 token 汇总，旧请求结束不会提前恢复新请求期间的工作。
- 博客画廊前两份预览准备完成即可展示，保留最多两份待完成预览及逐帧调度。其余页面继续逐步加载并使用作者信息占位；失败回退和普通目录保持可用。

补充验证：TypeScript、127 项相关测试、生产构建和 60 组路由／样式 SSR 检查通过，另覆盖经典原版深色、非法偏好和权限隔离。浏览器确认原版明暗刷新与返回记忆、四项键盘循环、跨页配色以及四套功能页零背景画布。生产浏览器采样仅用于观察实际导航与预览准备时机，不把画布删除推算成未实测的 FPS 提升。

本机生产预览的四次导航采样中，点击至目的路由内容更新约 33–110ms；画廊在约 1.2 秒后、12 份预览中仅两份完成时显示，离开画廊的 pending 事件中观察到其工作已暂停。该样本含热缓存且没有统一节流，不作为跨环境提速比例。另验证了快速连续点击的最后目的地、前进／后退、390×844 的四项菜单和手机底部导航；720×450 的放大等效视口中菜单完整可见。所列浏览器流程未发现脚本或水合错误。

## 原因与修改

- 在开发预览中复现了第一次进入社区约 1.2 秒的等待：页面响应约 1 秒，随后还要加载页面脚本和社区组件。当前 3008 使用 Next.js 开发模式；框架在此模式下关闭 route prefetch，并按需编译，不能把它作为生产速度。
- 共享顶栏已隐藏玻璃镜片，但原组件仍测量标签、复制文字、观察尺寸并运行 RAF 动画。顶栏改为原生 Next Link，保留原布局、当前路由与完整标签，移除隐藏镜片；useLinkStatus 提供即时细线反馈，点击不等待视觉动画。
- 生产模式下，加载完成后通过 idle callback 分批准备最多五个公开主导航目的地，间隔 1.2 秒；指针、键盘或触摸意图也会准备当前目标。悬停博客入口不再批量请求预览文档，作品仍在实际进入画廊后按既有队列加载。
- 社区的关键 lazy chunk 与路由数据同时准备，消除先等页面、再等组件的串行加载；资源分类也支持有界的查询链接预取。
- 省流、慢速连接、隐藏页面与正在导航时暂停可选预取，交互时让出空闲工作，清理时取消任务。只处理站内明确的公开导航；排除账号、管理、编辑、下载及任意查询，短期去重 map 最多 16 项。
- 动态场景改为首帧绘制之后再初始化，静态背景先展示。离开页面时取消尚未开始的初始化，即使旧回调已被交付也不会分配画布或 GPU 上下文。减少动态时仍只画静态帧。

## 验证与边界

首轮优化的 TypeScript、107 项相关测试以及独立目录中的 Next.js 生产构建通过。测试覆盖预取白名单、空闲工作取消、慢网与隐藏状态、首帧和卸载竞态、导航打断、未保存草稿保护、画廊队列和全站样式。构建有既有 CSS 的 autoprefixer 兼容提示，未阻塞构建。

真实浏览器确认另外两套首页在桌面和手机尺寸均无底部操作栏及主按钮箭头；顶栏不再生成镜片，也不再为其调度动画。生产模式已观察到分批 RSC 预取，点击反馈约 1ms；一次本机主导航样本内容更新约 50–190ms。这里统计 DOM 更新，不将 RAF 回调数当作屏幕帧率；不同环境的冷启动与热缓存数字不能当作严格的前后对照。

3008 保留热更新开发预览；3018 为本机生产模式预览，使用相同站点数据，不迁移或复制数据库，不对外部署。生产预览是构建快照；后续改动需重新构建并重启对应的本地进程。原始截图和性能采样保存在公开仓库之外。
