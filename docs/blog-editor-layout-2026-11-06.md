# 博客编辑工作区布局

本轮按用户明确选择的 Google Stitch 工具画布布局调整 `/workspace/blog` 及共用的博客编辑器。参考 [Stitch 官方画布介绍](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-ai-ui-design/)，使用其以画布为主、工具按需展开的组织方式，沿用 IAVSE 的操作语义与现有博客内容。

模式为 Operate：用户直接编辑自己的页面，保留资料、图片、主题、排列、私有草稿与公开版本之间的原有规则。

- 顶部收为 64px 的操作栏，保留返回网站、保存状态、文字版本、预览、发布设置与保存。手机使用两行工具栏，保存按钮采用短标签，完整名称仍供辅助技术读取。
- 左侧改为窄工具轨，图层、样式、插入和贴纸通过同一内容面板展开。再次点击当前工具或关闭按钮可收起；关闭后焦点回到对应工具。
- 画布默认不打开左右面板。1600px 窗口中，中央画布为 1528px 宽；原有 React Flow 平移、缩放、适合宽度和节点编辑继续使用。
- 选择画布文字只选择节点，属性面板由明确操作打开，避免编辑时额外挤动画布。手机的内容面板和属性面板互斥；属性关闭后焦点返回其触发按钮。
- 撤销、重做、选择、平移、缩放和整齐排版放在底部悬浮工具条中；页面预览继续保留同一画布实例及其编辑状态。
- 新布局样式由 `blog-editor-workspace.css` 及 `data-editor-layout="canvas"` 共同限定，防止公共站点的旧标题、表单与玻璃主题规则改写工作区尺寸。保留浅色和深色工作区，页面作品自身仍使用作者设置。
- 工作区样式也由专用服务器路由直接导入，保持首次加载时的样式完整。

## 验证

525/525 单元测试、TypeScript、生产构建和隔离数据目录的博客编辑 HTTP 集成通过。新增回归覆盖面板开关、选择文字不自动打开属性、手机面板互斥，以及仅操作工作区不会改写博客资料与设计。

浏览器验证覆盖 1600px 桌面、900px 中等窗口和 390px 手机模拟：无文档横向溢出，悬浮工具条处于视口内；手机预览与发布图标宽度均为 17px，面板标题为 13px。图层、样式、贴纸搜索、属性开关、焦点返回、平移与缩放均可操作。实际行内修改后撤销恢复了已保存状态，预览返回后仍只有一个画布；没有保存或发布测试编辑。返回链接仍指向网站首页。

本轮不改发布 API、权限、真实用户数据或安装包。参考图、页面截图与本机验收数据仅存放在 `/tmp`。

## 液态毛玻璃细化

工具布局与博客内容保持原样。编辑器外壳使用静态蓝、青绿和少量暖色环境光；工具轨、悬浮工具条、内容面板、属性与发布面板共用半透明表面、斜向反光、内侧亮边与柔和发光。文字和作品画板不应用模糊。

模糊仅在这些工具表面使用浏览器原生 backdrop-filter，桌面 18px、手机 10px；面板内部不再叠加模糊，不新增动画循环、指针跟随、WebGL 或依赖。不支持背景模糊时使用不透明底色，系统减少透明度时同样使用实面。浅色与深色分别设置表面和文字颜色。

同时修正 761–900px 顶部按钮挤在标题上的情况，以及手机内容面板因网格定位多偏移一列的问题。样式仅由现有工作区 CSS 承载，未修改博客保存、发布、撤销或首页滚动逻辑。

本轮 525/525 单元测试、类型检查及生产构建通过。浏览器覆盖 1600px、800px 和 390px：工具和面板无横向溢出，手机内容面板左边界为 64px；缩放、平移工具切换、预览返回及面板开关后仍保留单个画布，草稿状态保持已保存。减少透明度模拟切换为白色实面和 0px 模糊。仅验证现有内容，未保存或发布测试数据。
