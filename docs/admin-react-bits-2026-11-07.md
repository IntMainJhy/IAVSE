# React Bits 后台组件与动效

按本次澄清后的需求，后台使用 React Bits 组件库中的实际源码组件，不使用商业后台组件库，也不复制 React Bits 官网的整页布局。

- `SpotlightCard`：审核待办卡片的指针聚光、渐变边缘。关闭 ambient、grain、flare 和 proximity 扩散；触屏和减少动态效果模式下不启动鼠标跟踪。保留静态键盘焦点。
- `StarBorder`：概览刷新按钮的流动边框与点击反馈，仅放置一个实例。组件在不可见时停止动画，按钮光效被裁剪在控件内，避免横向溢出。
- `AnimatedContent`：统计和待办的挂载渐入，距离 10–14px、时长 0.4–0.45 秒，待办间隔 0.04 秒。保留 SSR 可见内容，使用组件自带 GSAP context 清理。没有 pin、scrub 或滚动接管。

源码来自 React Bits 官方 TS-CSS registry，完整原许可在 `docs/licenses/React-Bits.txt`，来源及修改记录在 `THIRD_PARTY_NOTICES.md`。Ant Design 的临时依赖已移除。

后台继续使用真实数据、现有卡片布局及权限。深浅主题通过服务端读取 Cookie 初始化，客户端同步切换，避免图标与卡片先后切换。原生表单、表格、弹窗和编辑器共享主题变量。

侧栏展开使用 CSS 网格过渡，收起内容使用 inert 和 aria-hidden；桌面与手机共享展开及选中状态。手机抽屉滑入/退出动画可中断，导航时立即关闭；旧的退出回调不能关闭重新打开的抽屉。后台链接取消自动预取，避免打开侧栏时提前加载全部管理页面。普通子页面的短渐入不会与 React Bits 概览渐入叠加。

验证包含 539 项测试（新增快速开关抽屉、Escape/减少动态效果、过渡清理）、生产构建、类型检查及隔离社区 HTTP 流程。浏览器检查组件渲染、实际跳转、深浅主题、390px 手机布局、侧栏展开及抽屉 Escape/导航关闭。

## 中性色与交互状态复查

逐页检查 18 个管理视图的浅色、深色及 390px 布局，覆盖概览、社区各队列、三类站点内容、文件、分类、设置、回收站、日志和文章编辑。主要页面背景与控件无偏紫底色，无整页横向溢出；博客审核中的作者页面预览保留作者自身配色。

修复公共站点液态样式向后台语言弹出菜单渗透的问题：菜单及选中/悬停/焦点使用后台中性色，不再使用蓝色渐变玻璃。统一按钮悬停、输入框焦点、表格操作、日志详情和页面边缘滚动条底色。

实测侧栏普通行高 39.5px、选中行高 41.5px，会在选中变化时产生 2px 位移；改为固定行高并预留透明边框。普通子页面切换只淡入，不再移动整个表单/表格；React Bits 卡片挂载、聚光及边框效果保留。手机编辑语言按钮采用等宽四列，长面包屑省略以避免挤压顶栏控件。

## 弹层与表单提示复查

内容预览改为在 React 完成预览内容布局后打开原生 dialog，避免先出现空框再重新居中。使用原生 display/overlay 离散过渡提供短淡入淡出；保留焦点约束、Escape 关闭及快速重开，关闭后用 preventScroll 将焦点交还预览按钮。弹窗开启时锁定背景滚动，稳定滚动条占位；手机端限制宽高并支持内部滚动。

语言列表保持挂载，关闭时 hidden/inert，使用短透明度和 4px 位移过渡；只在后台作用域启用这套动效，原生 select 和 option 使用同一主题。全局操作提示移到固定浮层，避免插入内容区后推移表单；编辑错误区预留空间，正文链接面板改为浮层并支持 Escape 和焦点返回。统一错误、成功、警告、辅助文字及文件选择按钮颜色；手机输入字体为 16px。

浏览器覆盖 1440px、390px、320px 与浅深两种主题：语言菜单、预览均未越界，预览开关前后主区域横坐标和滚动位置一致；验证快速关闭重开、焦点返回、减少动态效果、文件下拉选项及全局提示不推移内容。检查仅临时填写本地内容并调用不保存的预览接口；验证后恢复输入和原有本地草稿，没有保存、发布或修改账号密码。

机械扫描仅提示后台字号、圆角及遮罩不在公开站点 DESIGN.md 的抽样范围内；这里保留用户指定的后台中性色和现有卡片规格，未将前台蓝色玻璃 token 套到后台。
