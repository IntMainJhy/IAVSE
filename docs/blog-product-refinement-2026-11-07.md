# 博客产品展示：浅色界面与交互细化

本轮只细化 `/blogs` 下半段产品宣传的尺度、内容、背景及交互连续性。上方 3D 空间、Gallery 数据与操作保持原样；下半段继续使用浅色局部画布和原生文档滚动。本文记录当前实现、素材来源及本轮已完成的浏览器与自动化验证；独立视觉复查无 UI 修正项，唯一持久化记录同步项已完成，等待 reviewer 对记录修正复核，不沿用前轮终审结论。

## 设计参考与范围

参考官方 [Apple MacBook Air](https://www.apple.com/macbook-air/) 的产品主体尺度、标题与说明层级，以及 [Framer Design](https://www.framer.com/features/design/) 的编辑画面与功能说明关系；后者当前跳转至 [Framer Design 页面](https://www.framer.com/design/)。本次仅借鉴视觉层级和用真实编辑画面说明能力的方式，不复制这些网站的素材、品牌内容、黑色背景或滚动劫持行为。

新的局部底色为中性近白（#f7f7f5），主文字（#25282d）、正文（#5e646e）、分隔线（#dfe1e3）和蓝色创建操作保持清楚层级，浅深全站主题下均保留浅色产品区。移除原先用 `100vmax` 扩散阴影与 `clip-path` 延展背景的做法，背景由实际局部容器承载。

## 内容与组件

- **开场**：压缩高度，桌面将标题和说明／操作并排；“创建我的空间”进入 `/workspace/blog`，“体验画布”定位到下方真实演示。手机按内容顺序堆叠。
- **画布**：宽幅材料背景承托 `HomeBlogCanvasDemo`，画布窗口默认固定，不使用 GSAP 变换。下方三项功能说明为自由布局、字体与配色调整、编辑与预览切换。演示继续支持拖动、文字与颜色修改、撤销、重置和预览；改动只在本页演示内生效，不保存到账号或触发发布。
- **外观**：`BlogProductLooks.tsx` 用一张大预览配三个语义标签，分别展示作品集、个人履历和内容专栏。三张原有截图始终挂载于同一个固定宽高比（900/1015）区域，通过透明度切换；非活动面板使用 `aria-hidden` 与 `inert`，不参与指针或辅助技术交互。标签支持方向键、Home、End 与当前项焦点，手机显示三项紧凑选择及独立说明。
- **发布与分享**：同一真实 Maya 样例同时展示桌面与 390px 手机截图，主页操作打开 `/blogs/showcase/maya-lab`。文案区分草稿编辑和公开版本，不伪造发布成功或账号状态。
- **收束**：创建邀请之后保留原生折叠创作者目录，完整公开空间链接仍由服务端输出；目录数量不等同于上方 Gallery 展品数量。空状态保留创建入口。

六种布局与八种外观仍对应项目既有能力；作品集、个人履历和专栏使用三个不同的真实样例，不宣称是同一份资料自动切换后的结果。中、英、日文文案沿用同一结构。

## 滚动、恢复与窄屏行为

`BlogProductMotion.tsx` 仅为外观预览和发布装饰镜头提供一次轻量入场：桌面宽度至少 900px 且允许动态效果时，从 24px 位移和 .985 缩放归位，外观预览额外保留 2deg 的轻微透视；时长 .55s，完成后清空变换。不使用 scrub、pin、snap、滚轮拦截或额外虚拟滚动距离，交互画布不在动画目标内。

组件通过 `WeakSet` 记录已出现镜头，effect 使用空依赖数组，不因语言内容更新重建动画所有者。已在视口内或已看过的镜头保持最终位置；局部 `matchMedia` 在卸载时撤销自身动画。此实现用于减少滚动恢复、刷新、返回和媒体条件改变时的重复入场；本轮实际观测结果见下方验证记录。

767px 及以下改为单列说明与预览、三列紧凑外观标签、独立的活动说明和较小的桌面／手机组合画面；900px 以下及减少动态效果时不启用 GSAP 入场。图片预留固有尺寸，外观切换保留统一预览几何，正文默认可见；键盘焦点、原生目录开合及纵向文档滚动继续保留。

## 新增素材与来源

`public/media/blog-product/studio-light.webp` 为 1600×1067、8,158 字节的背景图，由内置 `image_gen.imagegen` 生成。它是具有摄影风格的浅色工作室材料背景，**不是现实工作室的实拍照片**；其中不含产品界面，实际演示由页面 DOM 叠加。生成原图为 1536×1024，经 sharp 等比调整到 1600px 宽、WebP 质量 84 编码。完整精确提示词位于同名 `.webp.json` 的 `generation.exactPrompt`，同时记录生成时间、原始尺寸和转换参数。

`public/media/blog-product/portfolio-mobile.webp` 为 390×844、17,060 字节的真实页面截图，来源 `/blogs/showcase/maya-lab`，2026-11-07 以中文（zh）界面、源提交 `48c9f0e` 捕获。使用 sharp 以 WebP 质量 88 编码，未裁切、未缩放、未使用 AI 生成。制作阶段已查看源图并与来源页对照，确认图中为 Maya 实际页面内容，而非 Loading 占位。既有样例素材的许可和署名继续适用；同名 `.webp.json` 保留捕获路由、视口、日期、提交和编码信息。

原有 `portfolio.webp`、`resume.webp`、`editorial.webp` 三张截图保持不变。素材来源扫描记录共 5 个 raster、缺失来源 sidecar 为 0；这项来源检查不代表页面布局、交互或性能验收通过。

## 本轮验证记录

- **自动化与范围**：最终生产构建、类型检查及 572 项测试通过；使用独立临时数据目录的首页 HTTP 检查通过。核心 3D 源文件、其 CSS 与 `BlogSpacesPage.tsx` 未改；原 `100vmax` 扩散阴影和 `clip-path` 背景已移除。
- **六种显示状态**：实际浏览器检查浅色 1440、768、390、320px，以及全站深色 1440、390px；下半局部均保持 #f7f7f5 浅底与深色字，文档横向溢出均为 0。窄屏工具栏保持不换行、40px 高，中文标题使用有意断行。
- **切换与恢复**：桌面、手机连续切换外观标签，预览高度差与文档顶部位置差均为 0。通过 Next 示例页往返后滚动差为 0，产品根节点仍为 1 个；桌面与手机重载后滚动差为 0，观察期页面错误及 layout-shift 记录均为空。移除外观组件的 locale key 后，zh／ja 切换保留选中的 resume；切回 zh 后的重载保存状态检查通过。
- **画布与指针**：鼠标拖动标题从本地坐标 (40,72) 到 (79,96)，窗口顶部位置差为 0；CDP 触摸模拟拖动从 (40,72) 到 (79,101)，页面滚动差为 0。`QuantumPointer` 的编辑区域选择器在本区抑制波纹，现有 10 项测试覆盖进入时清除、区域内不绘制及离开后恢复，本区实测波纹透明度为 0。
- **滚动与动态偏好**：输入 12000px wheel 可到真实页底，pin-spacer 为 0。启用减少动态效果并等待 matchMedia 清理后，两个装饰 camera 的 transform 均为空。“体验画布”锚点定位后标题顶部为 105.8px，scroll-margin 为 106px，未被导航遮盖。

以上为浏览器模拟尺寸、CDP 触摸及指定观察期的结果，不等同于真机验收，不保证所有设备帧率，也不据此宣称所有状态 CLS 为 0。独立 reviewer 已对 14 张截图完成视觉复查，均匹配并达到目标，无需修改 UI；首轮唯一 material fix 为持久化设计记录同步。`DESIGN.md` 的 Scoped Blog Product Film 与 `.impeccable/design.json` 对应命名空间同步后，reviewer 复核该项为 `resolved`，`remaining: clear`，最终 `disposition: ship`；该次复核结论仅覆盖已评分的记录同步修正。
