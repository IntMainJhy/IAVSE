# GSAP 页面切换衔接

本轮接续 [11 月 5 日的点击反馈与博客预加载](performance-2026-11-05.md)，替换主导航的原生页面快照流程。保留页面尺寸、首页玻璃场景、真实点阵波纹和博客空间的既有 3D 模板。

## 导航与动效

- 主导航通过草稿保护后，在同一次点击事件中立即执行 `router.push`。不等待下一帧、离场动画、原生快照或定时器；系统减少动态效果时使用普通 Next Link。
- 根级 GSAP 控制器统一管理主导航的离场、提交与入场。离场 140ms、入场 320ms，最多四个主要内容块以 10px 位移和透明度衔接，错开 25ms；不变换固定导航、全页容器或 3D 世界。
- 首页与内页之间使用一个固定、仅改变透明度的背景衔接层，避免复制 DOM 或读取 WebGL 画布。衔接层不接收点击，始终位于独立的点阵波纹下方，完成后隐藏并释放合成提示。
- `PageMotion` 在布局提交时直接通知根级时间线，无须持续观察整棵 DOM。主导航只有一个动画及暂停状态的控制者，社区内部导航和资源筛选保留原有局部 GSAP/FLIP。
- 主导航入场选取有限的顶部内容，不依赖滚动复位之前的可见性判断，解决从首页底部跳转时漏掉入场的问题。

## 渲染与恢复

- 离场及入场期间暂停首页和内页背景的连续计算，保留已绘制的画面及现有资源；新挂载页面读取根级状态，首次模型/GPU 初始化等到入场结束，避免抢占提交帧。
- 点阵点击波纹继续独立绘制和向外传播，保留原有几何、大小与频率。博客文档预加载、两路队列、整体准备好再展示的策略不变。
- 快速连续导航中断前一条时间线；旧完成回调不能清理新转场。其他内部链接、筛选或重定向提交时立即释放旧转场，让新页面自己的动画接管。
- 后退、草稿取消、动态效果偏好改变、页面隐藏和卸载都会恢复原样式、隐藏衔接层并释放暂停。失败响应另有 4 秒恢复上限，超时不重复发送导航。

## 验证范围

- 回归覆盖同步导航、真实事件阶段的草稿保护、原生输入的微任务检查点、快速连点、重复提交、不同目标接管、超时、减少动态效果、iframe、可见性、卸载及 GPU 加载竞态。
- Ego 生产环境首轮样本：首页到资源的 DOM 提交约 70ms，资源到博客空间约 64ms；两次观测窗口在点击后未记录到超过 50ms 的主线程长任务。入场结束后样式和衔接层均恢复，波纹跨页继续，博客预览为 12 个，内部仍为 `preserve-3d`。这些是本机样本，不代表其他网络或设备的固定耗时、帧率。
- 全量单元回归 **485/485**、TypeScript 检查、生产构建通过；首页和资源 HTTP 集成测试使用临时数据目录通过。
- Ego 补充验证：长页滚动后提交时仍有入场位移，随后正常回到顶部；连续主导航、草稿取消模拟、资源筛选与历史返回正常。390px 手机菜单自动关闭、无横向溢出、12 个预览及 3D 保持；系统减少动态效果时没有整屏转场。桌面首页标题仍为 32px、390px 手机约 21px。

## 首页进入博客空间的专项复测

用户反馈这条路径仍有停顿后，重新记录了 Ego 生产页面的 CPU profile、Long Tasks、Long Animation Frames、RAF 间隔和 iframe 挂载时序。

### 定位与修改

- 一次进入出现约 84ms 的主线程长任务：已卸载首页的 `HomeMotion` 在执行 `matchMedia.revert()` 时，仍初始化了从未滚动到的 `startAt` 动画，反复进入 CSSPlugin 和 `getComputedStyle`。真实脱离 DOM 的首页现在先停止所属 ScrollTrigger，再终止所属 context；移除已停止的 trigger 条目，避免 context 默认 kill 再次触发还原。连接中的 StrictMode、依赖变化及减少动态效果仍完整 `revert()`，不会影响其他组件的动画。
- 展廊此前在主导航入场结束前创建完全部 12 个 iframe。现在读取根级转场状态，等入场结束后，通过“下一帧 + 后续任务”分批准入，每次只增加一张、最多两张未就绪。缓存 HTML 仍需解析和布局，因此缓存命中也遵守调度；隐藏、移出视口、再次导航及卸载会取消后续工作，任务执行前另检查同步开关，覆盖 React 清理之前的竞态。
- 预览卡片使用 `memo` 和稳定选择回调；每个文档就绪不再重新渲染全部卡片。每张卡片的 ResizeObserver 合并为场景统一设置缩放，保持原先整数 `clientWidth / 1200` 的结果。
- 最后一张就绪后再让出一帧，随后统一显示；原有漂浮在整体淡入完成后继续，避免首次显示和 12 张卡片漂浮在同一时刻启动。模板、文档权限、卡片空间坐标、相机路径、大小、点阵波纹及预加载缓存不变。

### 验证

- 同一本机的一次优化前/后采样：84ms 长任务在复测窗口中不再出现；观察到的最大正 RAF 间隔由约 117ms 降至约 48ms。仍有样式/合成相关较长帧，不能据此承诺固定帧率或所有设备没有停顿。
- 复测中 `/blogs` DOM 约 59ms 提交，波纹仍显示；入场在约 362ms 结束，iframe 随后分批创建。12 个文档约 827ms 就绪，整体淡入后再开始漂浮。这是把工作错开后的本机时序，不是通用加载速度承诺。
- Ego 验证桌面和 390px 手机：12 个原有预览、`preserve-3d`、全部缩放值与实际卡片 `clientWidth / 1200` 一致；没有横向溢出。点击聚焦、Escape 返回、再次从首页进入、手机菜单关闭及减少动态效果直接访问均正常；主题 iframe 中脚本数为 0。
- 新增卸载/StrictMode/无关动画保留、分帧任务取消、并发上限、加载竞态、稳定回调、统一显示与漂浮时机等回归。全量 **499/499** 测试、类型检查、生产构建和首页 HTTP 集成通过。

## 转场连续性与首次渲染复查

本轮继续保留原有 12 张卡片、模板、空间几何、相机动画、点阵波纹和显示尺寸，处理上一轮未覆盖的工作阶段：

- 转场遮罩此前在提交时从离场至多 0.16 的透明度跳到 0.72，形成视觉突变。遮罩现在独立于离场内容的 GSAP context，从当前透明度继续淡出；立即导航、320ms 入场、取消和超时恢复保留。
- 预加载网络返回后，仍会立即解析和序列化 HTML。下载与文档处理现在分开排队，下载保持两路并发；解析每帧后只处理一份，转场或页面隐藏期间暂停，执行前再检查当前状态。缓存、优先级、失败回退及 24 份上限保留，队列排空后移除监听器。
- 首页两个动画组件此前分别调用全局 `ScrollTrigger.refresh()`。改为共享调度，同帧合并为一次，导航期间保留脏标记但不刷新，取消导航后只刷新仍连接的组件，卸载后取消迟到工作。
- 首次背景创建的 context、编译、结果检查、几何上传和尺寸初始化拆成可取消的任务。支持时使用 [KHR_parallel_shader_compile](https://developer.mozilla.org/en-US/docs/Web/API/KHR_parallel_shader_compile) 查询非阻塞完成标志，成功路径不逐个同步检查 shader；不支持扩展时仍在结果检查前让出绘制机会。编译轮询有 8 秒上限。快速切页、隐藏或离开阅读页只取消未完成的初始化，旧结果不能覆盖新任务，已就绪背景继续跨页复用。
- 场景 ResizeObserver 忽略未变化的宽高，避免初次重复通知打断正在进行的卡片聚焦。真实尺寸变化仍使用原计算公式重新布置。

验证：全量 **524/524** 单元测试、类型检查、生产构建和独立临时数据目录的首页 HTTP 集成通过。Ego 本机生产复测记录到跨页波纹 opacity 为 1、12 个预览、原有 `preserve-3d`，且所有卡片缩放与 `clientWidth / 1200` 一致；点击聚焦和 Escape 返回正常。连续进入社区、首页、博客再快速切至资源后，遮罩正常释放，背景继续运行。390px 手机菜单进入后自动关闭，12 个预览及缩放正常、没有横向溢出；系统减少动态效果时卡片动画为 `none`、背景静止，恢复后正常运行。

一次复测窗口内没有超过 50ms 的主线程 Long Task。环境中同时观察到约 1 秒、无脚本且 `blockingDuration` 为 0 的 RAF/Long Animation Frame 空档，不能把它当作应用 CPU 阻塞或据此宣称固定帧率提升。首次预览仍须完成各自文档布局，拆分初始化旨在减少集中执行，并不承诺所有设备都没有等待。

## 首页四章展示的连续交接

本轮范围为首页下方的博客空间、编辑画布、Skills 和资源四章，不改主导航路由转场、点击波纹及博客空间的 3D 展廊。

- 桌面四章固定为视觉在左、说明在右，沿用第一章的尺寸和同一 sticky 舞台。相邻画面在共同的滚动区间交叠，消除旧画面完全消失后才进入下一章的空档；去掉倾斜和大幅推近，保留小幅纵向、纵深变化。
- 说明文字在交接点先退后进，避免两段句子叠在一起。章节激活、`inert`、`aria-hidden` 与底部导航跟随实际 GSAP 播放位置，而非提前变化的原始滚动值；编辑器和资源演示不施加坐标变换，原有编辑与点击保持有效。
- 实测章节跳转时，布局刷新调用会先把滚动位置设为零，再恢复到中途位置，从而打断原生平滑滚动。共享刷新调度现在在滚动期间保留脏标记，到 `scrollEnd` 后再执行；排队后再开始滚动、导航、隐藏与卸载也会重新检查或取消，不增加逐帧轮询。
- 移除与主时间线竞争同一节点的首章入场动画，出场使用明确的起止值。动画端点不依赖布局尺寸，不在刷新时重新采样淡出中的状态；舞台视觉层停用通用链接的 CSS 透明度与变换过渡，避免与 GSAP 叠加导致首章滞后。手机与较矮窗口继续使用自然文档流；系统或手动减少动态效果时全部内容直接可读。
- 下方点阵波浪改为连续蓝银色折射柔光，复用已有不透明背景着色器，移除桌面的 6,048 个／手机的 2,016 个背景粒子及其独立绘制。首屏原始 Blender 玻璃不变；光弧位于下缘，随滚动缓慢变化，在页尾前淡出。隐藏、离屏及减少动态效果继续停止连续动画。

验证：全量 **533/533** 测试、类型检查、生产构建通过。回归覆盖正反向逐段采样、连续可见的画面、文字不重叠、实际播放位置与交互一致、稳定的画布坐标、章节按钮落在阅读区间，以及既有刷新合并和卸载清理。Ego 生产页面检查了四章、局部画布编辑与重置、390px 手机无横向溢出、减少动态效果恢复自然流；新背景实际 WebGL 编译成功。设计扫描只有已有样式与本地规范之间的提示，未扩展修改其他页面的字号与配色。
