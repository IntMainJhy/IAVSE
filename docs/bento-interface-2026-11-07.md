# Bento 控制台与资源索引

拥有者后台统一采用 16px 圆角、轻阴影与品牌蓝。浅色以白色卡片和 `#f5f5f5` 画布为底；深色后台与资源索引使用 `#1c1c1f` 卡片，画布均为 `#111113`。首页的折叠玻璃与原生滚动、公开详情保留各自设计；法律咨询保留律师名片与真实资料，共享资源索引的中性导航框架。

后台覆盖概览、社区治理八个入口、共享内容审核、文章／项目／资源列表与编辑器、文件、分类标签、设置、回收站及日志。工作页按标题与主操作、筛选条、内容或审核面板组织；窄屏保留清楚的单列阅读顺序、44px 主要操作与局部可横向浏览的表格。概览保持不同跨列，原有 AnimatedContent、SpotlightCard 和 StarBorder 继续使用；表单、表格和审核工作面保持稳定。

文件引用默认折叠显示数量，展开保留所有链接，并在 260px 范围内滚动。长文件名最多显示两行，完整名称保留于标题提示；个人资料引用跳转到有效公开资料页。后台地址、当前页面和浏览器历史保持一致，侧栏切换后的返回、重载与查询链接仍指向正确工作区；未保存修改的离开提示只出现一次。手机抽屉连续开合时从当前位置反向运动。文章、项目和资源列表在同一集合的搜索与分页保留可见行并宣布忙碌状态，更新完成前禁用写操作；切换内容类型或回收站集合时清除上一集合的行。

资源入口以展示内容为中心：标题与分享操作之后直接显示轻量分类数量和真实目录，Connect 放在目录之后。搜索统一收成 44px 小按钮，点击后在工具栏上方横向淡入固定高 48px 的非模态搜索框，不推移正文。使用浏览器原生 Popover，保持输入框处于原有表单内；收起不丢查询，Enter 提交，Escape 与关闭按钮归还焦点，点击其他位置保留其焦点行为。原有 Next Form、原生表单和工作区即时筛选分别保留，分类、工具、状态、分页及隐藏字段继续有效。未提交的输入会在导航提交时与查询重新同步，避免文字与结果不一致。刷新、搜索提交和分类切换均回到紧凑按钮状态，保留活动查询标记、结果提示及表单字段；弹层只在主动点击时展开，连续反向操作依据原生开合状态，避免延后的 React 状态错判。手机视口／滚动回调合并到一个动画帧，定位未改变时不重复写入样式。

Skill 目录参考 [vibeui.top](https://vibeui.top/?lang=zh) 的“上方筛选、下方通栏内容”阅读顺序，去掉左侧分类与按类型重复分段。桌面卡片按 4／3／2 列适配，620px 以下单列。手机的工具与类型各为一行横向可滑动选项，保留 44px 触控区域，选中的选项在刷新、切换和尺寸变化时自动保持可见。收录数量仍为当前真实的 10 项；来源、支持工具、标签、详情、安装和许可入口全部保留。

法律咨询的资源标签移到 1160px 正文之外，与其他索引共用外层宽度、位置、字体和手机横向标签栏。切换时不改变导航框架，活动项不通过改变字重挤动相邻标签。索引与法律页采用相同浅深色中性画布；法律页也不启动隐藏的量子场景。律师介绍、证号、服务内容及联系方式不变。

实现采用已安装的 Apple HIG 布局、搜索与控件规范，以及 shadcn 的组合与可访问性原则、Impeccable 的布局检查和现有动效规范。未为展示目录加入无关视频／3D 效果或新组件库。卡片悬停、React Bits 效果和首页原生滚动保留；搜索只过渡透明度与位移，减少动态效果时取消过渡。

资源范围包括 `/resources` 的分类视图与直接 `/docs`、`/skills` 索引。连续中性背景覆盖导航到页脚，索引及法律咨询不运行隐藏的量子背景循环；其他详情与社区的既有背景效果保留。所有统计、查询、文件、发布和审核继续使用真实数据与原有入口。

后台 20 个视图在 1440px、390px 及浅深两种模式下完成 80 项页面检查，未见横向溢出或页面错误，手机输入字号均为 16px。548 项测试、类型检查和生产构建通过；导航地址、返回与重载一致，资源查询切换无位置变换。未增加图片资产或依赖。


本轮展示页复查覆盖 11 条实际页面路径，在 1440px／390px、浅色／深色下记录 44 个状态：无横向溢出、页面错误或搜索展开导致的内容与滚动位移；搜索面板始终在视口内，输入为 16px。资源、文档、Skill、网站工具与法律咨询的每个顶部标签横坐标一致。手机 Skill 首张内容卡片约在 648px 出现。搜索提交与分类参数保留、关闭后保留查询、Escape 焦点恢复及减少动态模式均按实际浏览器交互核对；独立界面复查通过。


后续动效复查将资源、文档、Skill、法律咨询及其分类视为同一稳定框架。局部分类与主导航两个 GSAP 控制器复用路径判定，切换只改变透明度，不再上下移动正文或错列延迟。Skill 分类的选中与未选中字重一致，卡片网格不因是否有搜索词而切换列数；结果仍随真实数据更新。手机搜索汇总保留屏幕阅读器播报和清除入口，分类数量行不会额外换行推动正文。选中项同时监听自身与容器尺寸变化，并合并刷新、翻译和尺寸回调。120 字连续查询在手机上正常换行。

法律联系按钮以当前语言的完整“复制微信号”标签保留宽度，成功后的确认图标采用短促淡入缩放，减少动态模式取消该动画；成功状态不改变按钮或信息区高度。焦点、联系锚点与轻量悬停反馈统一适配两种主题。

本次 559 项测试、类型检查及生产构建通过。实际浏览器检查覆盖 6 条路径、1440px／390px、浅／深两种模式的 24 个状态，搜索快速连续开合无正文／滚动位移、横向溢出或页面错误；资源分类及主导航切回资源的位移采样为 0。320px 刷新保持选中分类可见、搜索收起；120 字查询无溢出；复制确认前后按钮宽度与联系区高度差为 0。独立动效复查通过。手机检查使用浏览器尺寸模拟，未据此宣称真实设备的固定帧率。
