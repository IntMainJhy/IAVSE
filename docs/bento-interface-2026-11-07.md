# Bento 控制台与资源索引

拥有者后台沿用中性实面、16px 圆角、轻阴影和少量品牌蓝。浅色画布为 `#f5f5f5`、卡面白色；深色画布 `#111113`、卡面 `#1c1c1f`。内容管理主卡采用石墨灰渐变，白色主文字与柔和灰白说明。首页的折叠玻璃、原生滚动和公开详情保持各自设计；法律咨询保留律师名片，共享资源索引的中性框架。

后台概览以完成日常任务为中心。首屏为“内容管理”：新建文章和管理内容；项目、资源与文件为紧凑快捷入口。最近编辑紧随其后，保留真实类型的编辑路径、日期和空状态。刷新收为有明确名称的 44px 图标按钮。保留 StarBorder、SpotlightCard 和短促 AnimatedContent，不再让重复的零统计与审核卡片占据首屏。

审核与治理合并为原生折叠区，零待办默认收起；任一队列有待办时自动展开，汇总数字包含可访问名称，五个审核入口与各自数量全部保留。用户、公开主页、站点内容、流量和存储八项统计位于默认收起的“网站运行概览”；完整“访问数据”仍可展开使用日期、趋势与来源等原有功能。两个次要折叠区统一卡面、64px 标题行、箭头、焦点和减少动态模式。

侧栏将站点内容前移，分类、设置、回收站和日志归入“更多管理”。概览默认收起，进入对应子页时自动展开并保留正确选中状态和面包屑；桌面侧栏与手机抽屉复用同一导航。原有地址、历史、未保存保护、发布、审核和权限不变。文件引用仍默认折叠显示数量，展开保留全部链接并局部滚动；工作页的表单、表格和审核面板保持稳定。移除旧概览卡片的 59 条废弃样式规则。

此层级调整使用 Impeccable 布局规范与 Apple HIG 导航指导。桌面工作卡和快捷区采用不等宽两列，720px 以下单列；主要操作至少 44px。英、日文同步覆盖新增的功能名称。统计来自现有 API，不新增虚假使用频次、草稿或紧急程度数据，也不删除次要功能。

资源入口以展示内容为中心，搜索收成 44px 按钮，在工具栏上方展开固定高 48px 的原生 Popover，不推移正文。刷新、搜索提交及分类切换保持收起，保留查询、分类和表单字段；仅主动点击展开。连续开合依据原生状态，视口事件合并到一个动画帧，定位不变时不重复写入。Enter 提交，Escape／关闭归还焦点，外部点击不抢焦点。

Skill 目录参考 [vibeui.top](https://vibeui.top/?lang=zh) 的顶部筛选、下方通栏网格，采用 4／3／2／1 列；手机两组筛选分别横向滑动，选中项自动可见。保留真实收录、来源、支持工具、标签、详情、安装和许可。资源网格不因有无搜索词而改变列数；分类字重固定，长查询正常断行。

资源、文档、Skill 与法律咨询视为同一稳定框架，分类及主导航切换只改变透明度，不上下移动或错列延迟。法律页导航位于 1160px 正文外，与其他索引一致；索引及法律页不启动隐藏的量子循环。法律复制按钮保留完整本地化标签宽度，成功图标作短促反馈，减少动态时取消；真实律师资料不变。

验证：562 项测试、类型检查与生产构建通过，新增渲染检查覆盖零／非零待办、完整保留审核路径、最近编辑真实路由及安全文本。后台概览在 320／390／509／768／1440px、浅深两色下无溢出；桌面最近编辑约从 905px 提前到 421px，手机约 595px。折叠区可由键盘操作，五个审核入口、八项概览统计与完整访问数据均可展开。四个次要管理页的选中、面包屑和自动展开正确，手机抽屉及英日文显示通过。资源与法律此前的搜索、导航及减少动态模式回归验证继续保留。手机检查使用浏览器尺寸模拟，未宣称真实设备固定帧率。
