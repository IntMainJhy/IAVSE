# Bento 控制台与资源索引

管理概览和资源索引采用不同跨度的 CSS 网格卡片，统一 16px 圆角、轻阴影与 IAVSE 品牌蓝。浅色使用白色卡片和 `#f5f5f5` 画布，深色使用 `#1c1c1f` 卡片和 `#111113` 画布。

管理概览以待办汇总大卡、用户与访问数字、五类审核队列、最近编辑及文件存储组成。所有数字继续读取 `/api/admin/overview`；没有最近内容时展示真实空状态。详细访问数据保留在原有折叠区，左侧导航与发布、审核流程不变。React Bits 的 AnimatedContent、SpotlightCard 和 StarBorder 保留。

资源索引将搜索、分类数量、分享入口和 Connect 入口整合为发现网格，真实目录卡片采用不同跨度。范围包括 `/resources` 的分类视图和直接访问的 `/docs`、`/skills` 目录；详情、法律咨询、首页及作者自定义页面不做网格重排。索引使用连续中性背景，并仅在这个范围内隐藏旧的固定量子背景。

可点击卡片在精细指针悬停时缩放到 1.02；手机不依赖悬停，减少动态效果时取消缩放和过渡。窄屏按内容顺序堆叠，统计区保留双列，搜索与筛选继续使用现有表单和路由。

验证覆盖 320、390、768、1440、2048px 的浅深色模式、目录搜索、分类入口、手机抽屉导航及减少动态效果。539 项测试、类型检查和生产构建通过，独立视觉复核通过。未增加图片资产或依赖。
