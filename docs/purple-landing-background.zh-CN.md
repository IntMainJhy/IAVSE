# 青绿与浅蓝柔雾背景

首页通过 `src/components/landing/IavseLanding.tsx` 挂载 `IavseFlowBackdrop`；其他符合路由边界的平台页面由共享 `PortfolioRuntime` 挂载同一背景。左侧青绿雾团与右侧浅蓝雾团独立流动，中央留白，导航、标题、内容和按钮保持独立的可读层。用户选择了柔雾而非较强的带状卷动；当前时间节奏为 `0.12`，保持左右雾域各自缓慢变形。完整的壳层与作者内容边界见[平台 UI 说明](platform-ui.zh-CN.md)。

## 视觉参考的通用机制

参考效果由静态渐变底色、WebGL 二维流体层和边缘淡出共同组成。流体层把颜色与运动输入一个随时间演化的场，颜色被速度带动、拉伸并逐渐消散。初始自动注入可以在没有指针操作时形成流动；鼠标移动则给局部增加动量，使已有颜色发生偏转。

这种机制与 CSS 光斑平移有明显区别：平移主要改变一个完整渐变形状的位置，形状内部关系基本不变；流场会改变颜色边界的形态，产生拉长、弯折、汇合和残留。该分类用于解释视觉参考，并不要求当前首页呈现高对比色带；当前视觉取舍以用户选定的柔雾为准。

这些是效果层面的技术分类，不构成对任何外部实现或资产的引入说明。

## 当前公开实现

[`IavseFlowBackdrop.tsx`](../src/components/landing/IavseFlowBackdrop.tsx) 由独立实现代理在未读取参考源码的情况下原创编写。它使用原生 WebGL 的单次全屏着色，按位置、时间与指针状态直接计算颜色；不使用视频、外部背景图片或模拟纹理。

当前方法是解析流场与域扭曲：先由相交波形产生随时间变化的方向，再逐层扭曲采样坐标。`mist` 函数将两层柔雾色域 `sheetA` / `sheetB` 与 `opening` 混合；左右两侧分别以不同相位和纵向坐标调用它，形成各自缓慢变化的青绿与浅蓝雾团。柔和的 `leftAnchor` / `rightAnchor` 把雾域留在两侧，中央露出页面底色，避免手机端只剩一侧显色。每侧保留轻量的密度底值，内部形态独立流动而不整片消失。着色器时间采用 `uTime * 0.12`。鼠标运动轻微弯曲局部色域，运动量随后平滑衰减；自动流动始终保留，不会因第一次鼠标移动而关闭。

它没有求解速度、压力和散度，也没有逐帧保存染料状态，因此不是物理流体求解器。指针影响是对当前图形的局部变形，不代表持续保存的染料或真实流体涡旋。目标是实现适合 IAVSE 的流动氛围，不宣称与视觉参考逐像素一致。

## 参数与色彩布局

参数集中在背景组件的片元着色器与其输入更新逻辑中，目前没有单独的配置对象。

| 位置 | 作用 |
| --- | --- |
| `uSize` | 保持宽高比例，并用实际像素高度控制顶部留白。 |
| `uTime` | 驱动连续流动；着色器内的时间倍率控制整体节奏。 |
| `uPointer` | 指针在背景容器中的归一化位置。 |
| `uMotion` | 指针方向、速度影响与局部扰动强度；更新逻辑负责跟随和衰减。 |
| `current`、`mist`、`sheetA` / `sheetB` 与 `opening` | 控制域扭曲、每侧柔雾内部的覆盖与开合。 |
| `left` / `right` 的坐标与相位、`leftAnchor` / `rightAnchor`、高度遮罩 | 控制左右两侧独立的柔雾位置、覆盖范围和中央留白。 |
| `mint`、`sky`、`pigment` | 控制两侧青绿、浅蓝的混色。雾层的透明度由覆盖范围决定，透出下方页面画布。 |
| `clearance`、`lowerFade` | 控制顶部净区与底部淡出。 |

青绿与浅蓝用于背景和装饰底色。按钮、选中标签、图标和链接使用中性黑；[`iavse-landing.css`](../src/app/iavse-landing.css) 的 `--iv-action` 以及共享应用控件变量不会自动改变着色器颜色。调整柔雾时应同时核对着色器调色与组件内的静态渐变，避免动态和降级画面出现明显色差。

左侧青绿与右侧浅蓝逐渐淡为透明，露出浅色模式的白色画布。静态渐变的左侧核心与软边为 `#ace1ca`、`#e5f4ec`，右侧为 `#b6d9f5`、`#e8f2fc`。深色模式下首页雾层不透明度为 0.30，其他平台页面为 0.24，中央和底部露出各自的深色画布。背景在顶部约 100 像素内透明，随后逐步显色，底部再淡出到页面底色。左右雾域按容器归一化坐标定位，桌面和手机都应保留两侧构图。当前共享导航采用白色半透明渐变、24px 背景模糊与中性文字；它替代了先前的纯透明顶栏要求。中性的导航材质允许下方雾色透出。背景层不接收点击，也不遮挡导航与正文交互。

## 性能、输入与静态降级

- 使用低功耗 WebGL 上下文，不启用抗锯齿、深度或模板缓冲；渲染像素密度设有上限，并适当降低实际绘制分辨率，以适配宽幅柔和色场。
- 背景离开视口或页面进入后台时取消动画帧；重新可见后继续播放。缺少 `IntersectionObserver` 时使用滚动位置检查。
- `prefers-reduced-motion: reduce` 下只绘制静态画面，时间固定、指针扰动清零，不持续申请动画帧；偏好变化会实时生效。
- 仅支持悬停的精细鼠标输入产生扰动，触摸设备保持自动背景，不拦截页面滚动。鼠标位置按背景容器计算，事件在下一帧合并处理。
- 首帧 WebGL 绘制成功后隐藏静态渐变。初始化失败或上下文丢失时显示静态 CSS 柔雾，中央透出页面底色。当前上下文丢失后不自动重建，静态背景仍可使用。
- 卸载时停止动画、断开观察器、移除监听并释放 WebGL buffer 与 program。背景始终标记为装饰内容，辅助技术无需读取。

后续调整应分别核对正常动态、鼠标扰动、减少动态效果、离屏暂停和静态降级画面；柔雾的流动强度不应影响导航与正文阅读，也不应擅自改回用户未选用的强色带效果。
