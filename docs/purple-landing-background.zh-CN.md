# 青绿与浅蓝的空间柔雾背景

2026-11-13：在 `background` 分支进行的独立背景设计。用户选择“通透的空间感：柔光有远近，中间干净”。该分支尚未合入 `main`；主线已有交付与历史截图的范围不因此改变。

首页通过 `IavseLanding` 挂载 `IavseFlowBackdrop`，其他符合路由边界的平台页面由 `PortfolioRuntime` 挂载同一组件。保留白色页面、中性功能控件与原有布局。背景仍限于一个可见视口，向下滚过介绍区后自然退去，不铺满长页面，也不进入作者博客或编辑画布。

## 视觉结构

- 远处：宽阔、低密度的青绿与冷蓝光晕，位置较高、颜色较淡。
- 中景：两侧雾团保持柔软的体积，使用不同相位与重心，避免严格镜像。
- 近处：较窄的雾层带有缓慢变形的褶皱，色彩略深，和远处淡光拉开距离。
- 中央：稳定的柔和净区，标题、说明和导航保持清楚；交界连续渐变，没有垂直分色线。

设计用色为白色 `#ffffff`、远雾青绿约 `#def2eb`、近雾青绿约 `#7abfa3`、远雾蓝约 `#e3f0fc`、近雾蓝约 `#73a6e3`。它们是雾层自身的颜料值，叠加透明度后的实际屏幕颜色更淡。不会改写按钮、文本、图标和语义状态颜色。

## 公开实现

[`IavseFlowBackdrop.tsx`](../src/components/landing/IavseFlowBackdrop.tsx) 使用原生 WebGL 单次全屏着色。空间感由程序生成的密度、颜色、透明度及不同距离的轻微位移组成，不使用外部图片、视频、私有素材、模拟纹理或新增依赖。

`noise` 是平滑插值的二维值噪声；`cloud` 将三个尺度旋转叠加，避免明显的横纵网格。`plume` 用同一变形场构成中景和近景，近景的形变更明显。`leftVeil` 和 `rightVeil` 提供宽阔的远光。近层的浓度影响颜料颜色，使深处保留淡光、近处略有厚度。

它没有真实几何雾体、逐帧染料保存、压力／速度求解或真实光线散射，因此不是物理流体或体积渲染器。这里的“远近”是视觉深度表达，不是声称存在真实三维云体。

## 参数

| 位置 | 作用 |
| --- | --- |
| `uSize` | CSS 尺寸、比例与顶部像素净区；左右构图仍以归一化边缘坐标定义，手机两侧都显示。 |
| `uTime * 0.17` | 雾团变形的基础节奏；内部不同速度分别用于中景与近景。 |
| `uPointer`、`uMotion` | 指针或主触点的方向与扰动；输入跟随和衰减沿用现有生命周期。 |
| `plume` 的 `bend`、`far`、`near` | 三尺度连续变形与景深差异，没有锐利阈值轮廓。 |
| `leftVeil`、`rightVeil` | 较高、较淡的远处光晕。 |
| `leftDensity`、`rightDensity` | 将远光、中景及近景浓度合成，连续混合两侧色彩。 |
| `centerLight`、`breathingRoom` | 中央净区固定在标题轴线，指针不会拖走留白。 |
| `parallax` | 近层最大约 1.25% 的偏移，远层约为其 22%；小幅响应增加远近感。 |
| `clearance`、`lowerFade` | 顶部 100–300px 逐渐显色，背景高度 70% 起向底部淡出。 |
| `hash(gl_FragCoord.xy)` | 不超过半个透明度量化级的抖动，减轻浅色渐变的色阶条纹，不添加可见颗粒。 |

最终 alpha 通过 `1 - exp(-density * 1.55)` 平滑压缩，再叠加净区及上下淡出。输出为预乘透明色，避免半透明边缘发黑。深色模式仍由共享雾层的 0.24 不透明度控制，不改变页面主体和文字对比度。

## 降级与性能

静态降级由四个半透明径向渐变组成：两团近雾、两片远光，保留同样的两侧构图及中央留白。WebGL 成功首帧后隐藏降级；初始化失败或上下文丢失时自动显示。静态降级不承诺与某个动态时刻逐像素相同。

沿用原有低功耗上下文、像素密度上限和降采样；不启用抗锯齿、深度、模板缓冲或持续创建纹理。没有增加帧循环或全局滚动拦截。离屏和后台停止绘制，减少动态时只画静态帧，偏好实时生效。触摸与指针监听仍为被动模式，不捕获点击、不阻止原生滚动；卸载清理观察器、事件及 GPU 资源。

## 检查范围

检查桌面与 390／320px 手机两侧显色、中央净区、正常流动、指针／触摸、深色、减少动态、离屏暂停、WebGL 上下文丢失后的静态降级。着色器在浏览器真实 WebGL 上编译，并对不同时间、尺寸及扰动输入读取像素，确认其有变化且中央透明度明显低于两侧。该检查不构成所有手机 GPU 的性能保证。
