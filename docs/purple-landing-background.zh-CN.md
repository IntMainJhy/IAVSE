# 青绿与浅蓝柔雾背景

首页通过 `src/components/landing/IavseLanding.tsx` 挂载 `IavseFlowBackdrop`；其他符合路由边界的平台页面由共享 `PortfolioRuntime` 挂载同一背景。页面左侧偏青绿，右侧偏浅蓝。两团半透明的雾色在中央缓慢交融，正文下方仍可透出页面底色。用户选择了柔雾而非较强的带状卷动；当前时间节奏为 `0.12`，保持左右雾域各自缓慢变形。完整的壳层与作者内容边界见[平台 UI 说明](platform-ui.zh-CN.md)。

## 视觉参考的通用机制

参考效果由静态渐变底色、WebGL 二维流体层和边缘淡出共同组成。流体层把颜色与运动输入一个随时间演化的场，颜色被速度带动、拉伸并逐渐消散。初始自动注入可以在没有指针操作时形成流动；鼠标移动则给局部增加动量，使已有颜色发生偏转。

这种机制与 CSS 光斑平移有明显区别：平移主要改变一个完整渐变形状的位置，形状内部关系基本不变；流场会改变颜色边界的形态，产生拉长、弯折、汇合和残留。该分类用于解释视觉参考，并不要求当前首页呈现高对比色带；当前视觉取舍以用户选定的柔雾为准。

这些是效果层面的技术分类，不构成对任何外部实现或资产的引入说明。

## 当前公开实现

[`IavseFlowBackdrop.tsx`](../src/components/landing/IavseFlowBackdrop.tsx) 由独立实现代理在未读取参考源码的情况下原创编写。它使用原生 WebGL 的单次全屏着色，按位置、时间与指针状态直接计算颜色；不使用视频、外部背景图片或模拟纹理。

左右雾团分别通过 `mist` 计算密度和色调。两者使用不同相位，时间倍率为 `uTime * 0.12`。`mixPosition` 随高度、时间、两侧色调以及指针的水平速度偏移，两侧密度在同一片宽阔的区域内渐变。每个像素按 `blueShare` 得到局部青蓝比例。鼠标经过或手指轻触时，接触点附近的两色短暂趋近均匀混合，扰动随时间衰减。

它没有求解速度、压力和散度，也没有逐帧保存染料状态，因此不是物理流体求解器。指针影响是对当前图形的局部变形，不代表持续保存的染料或真实流体涡旋。目标是实现适合 IAVSE 的流动氛围，不宣称与视觉参考逐像素一致。

## 参数与色彩布局

参数集中在背景组件的片元着色器与其输入更新逻辑中，目前没有单独的配置对象。

| 位置 | 作用 |
| --- | --- |
| `uSize` | 保持宽高比例，并用实际像素高度控制雾层顶部的透明区域。 |
| `uTime` | 驱动连续流动；着色器内的时间倍率控制整体节奏。 |
| `uPointer` | 指针在背景容器中的归一化位置。 |
| `uMotion` | 指针方向、速度影响与局部扰动强度；更新逻辑负责跟随和衰减。 |
| `current`、`mist`、`sheetA` / `sheetB` 与 `opening` | 控制域扭曲、每侧柔雾内部的覆盖与开合。 |
| `mixPosition`、`leftAnchor` / `rightAnchor` | 左侧在混色坐标 0.02 至 0.84 间衰减，右侧在 0.16 至 0.98 间增强。两侧渐变重叠的位置随流动和手势偏移。 |
| `blueShare`、`stirring`、`alpha` | 相对密度决定混色比例。局部扰动使青绿和浅蓝更均匀，在两色交汇处略微增加雾层不透明度。 |
| `clearance`、`lowerFade` | 控制顶部净区与底部淡出。 |

青绿与浅蓝用于背景和装饰底色。按钮、选中标签、图标和链接使用中性黑；[`iavse-landing.css`](../src/app/iavse-landing.css) 的 `--iv-action` 以及共享应用控件变量不会自动改变着色器颜色。调整柔雾时应同时核对着色器调色与组件内的静态渐变，避免动态和降级画面出现明显色差。

静态回退叠加两个宽椭圆渐变，左侧核心为 `#ace1ca`，在半径的 42% 和 73% 处分别降至 0.62 和 0.20 不透明度。右侧核心为 `#b6d9f5`，在 44% 和 76% 处分别降至 0.65 和 0.22。两者继续向外变透明，在相交处透出下层颜色。雾层顶部 100px 保持透明，至 320px 逐渐显色，自背景高度的 79% 起向底部淡出。首页的 `.iv-backdrop-wrap` 固定铺满视口，其半透明青绿至浅蓝渐变在雾层下方从顶边显色。页面滚动时背景位置固定，雾色继续在其中流动。深色模式下，整个雾层在首页使用 0.30 不透明度，其他平台页面使用 0.24。

## 性能、输入与静态降级

- 使用低功耗 WebGL 上下文，不启用抗锯齿、深度或模板缓冲；渲染像素密度设有上限，并适当降低实际绘制分辨率，以适配宽幅柔和色场。
- 背景离开视口或页面进入后台时取消动画帧；重新可见后继续播放。缺少 `IntersectionObserver` 时使用滚动位置检查。
- `prefers-reduced-motion: reduce` 下只绘制静态画面，时间固定、指针扰动清零，不持续申请动画帧；偏好变化会实时生效。
- 精细鼠标移动时局部搅动雾色。主触点按下时在该处产生一次扰动，后续移动可改变混色方向，抬手或系统接管滚动时结束跟踪。输入使用被动监听，页面保留原生点击和滚动。
- 首帧 WebGL 绘制成功后隐藏静态渐变。初始化失败或上下文丢失时显示青绿与浅蓝交叠的静态 CSS 柔雾。当前上下文丢失后不自动重建，静态背景仍可使用。
- 卸载时停止动画、断开观察器、移除监听并释放 WebGL buffer 与 program。背景始终标记为装饰内容，辅助技术无需读取。

后续调整应分别核对正常动态、鼠标和触摸混色、原生滚动、减少动态效果、离屏暂停和静态降级画面；柔雾的流动强度不应影响导航与正文阅读，也不应擅自改回用户未选用的强色带效果。
