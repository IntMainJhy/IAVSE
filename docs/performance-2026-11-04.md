# IAVSE 性能优化记录 · 2026-11-04

本轮检查首页、3D 博客展廊、资源、社区、博客编辑器与后台首页。优化背景加载、滚动状态写入、公开目录查询，以及编辑器和后台的首次显示。保持现有视觉、交互、账号隔离与发布规则。

## 浏览器资源测量

在同一本地生产服务、Ego Chromium、中文界面、1440 × 1000 CSS 像素视口下禁用浏览器缓存，逐页完整导航。测量沿用 `scripts/performance-probe.mjs`，脚本仅统计 Resource Timing 中 `initiatorType === 'script'` 的条目。下表使用十进制 KB，表示解压后的脚本体积，不能换算为页面提速百分比。

| 页面 | 脚本 KB：优化前 → 后 | 变化 |
| --- | ---: | ---: |
| `/` | 1279.4 → 1280.0 | 基本不变 |
| `/blogs` | 1220.6 → 687.0 | 减少 43.7% |
| `/resources` | 1220.6 → 687.0 | 减少 43.7% |
| `/community` | 1321.6 → 788.0 | 减少 40.4% |
| `/workspace/blog` | 959.7 → 960.5 | 基本不变 |
| `/admin` | 812.5 → 810.4 | 减少约 2 KB |

博客展廊与资源页的脚本传输量从约 355.7 KB 降到 228.4 KB，社区从约 386.1 KB 降到 258.8 KB；这是本地响应的 Resource Timing 记录，不代表不同部署的压缩与缓存表现。

## 实现

### 阅读背景

点阵背景保留原来的三组曲线、相机、投影、颜色转换、指针响应和两个绘制图层，改为原生 WebGL 绘制。只导入 Three.js 的相机与数学模块，阅读路由不再为了这个背景下载完整渲染器与通用着色器库。首页光学玻璃及资源雕塑继续使用自己的 Three.js 渲染器。

桌面与手机的顶点缓冲在首次使用对应尺寸时分配，后续帧只更新 uniform；切换尺寸后复用已有缓冲。渲染失败、WebGL 不可用、上下文丢失、取消与卸载继续走原有回退及清理流程。减少动态效果、暂停与隐藏标签页继续停止持续绘制。

同尺寸、暂停状态的资源页截图对比，平均单通道像素差约 0.145/255，差异超过 20 的像素约占 0.16%。该记录用于核对渲染一致性，不能替代其他设备的视觉验收。

### 首页滚动

章节内连续滚动不再反复写入全部卡片的 `inert`、`aria-hidden`、激活标记和导航状态；仅跨越章节边界时更新。保留原时间线、聚焦关系、进入和退出效果，以及减少动态模式下的原生阅读顺序。

### 公开博客目录

- 在 SQL 中筛掉未公开、未允许发现的主页，逐条检查公开资格；找到 60 个合格主页后停止读取。
- 一次目录请求只判断一次旧站长主页是否被新主页替代，并复用当前行已读取的公开版本及作者状态。
- 目录直接读取封面字段和内容数量，不解析每篇文章的正文及私人草稿；完整主页和文章详情仍使用原有读取路径。
- 为目录排序、公开内容读取及投诉目标检索增加索引，不缓存权限结果或公开数据。

在同一临时数据库上比较旧、新读取函数：180 个主页，每篇公开正文 16,000 字节，9 次采样的中位耗时约 **9.4 → 3.5 ms**，返回结果逐项一致。这是合成目录读取测试，不是生产 API 延迟承诺。测试数据与边界检查见 `test/directory-performance.test.mjs`。

### 编辑器与后台

编辑器使用本次服务端请求中已按原权限检查的 `/api/spaces/mine` 数据初始化画布、草稿基线和主页地址，不再丢弃预载数据后重复 GET。没有成功预载数据时仍使用原有读取与错误处理。保存返回值与首次数据共用 `editorDraftLayout`，初次显示保持“已保存”，草稿签名仅在资料、布局或可发现性改变时重新计算；用户修改不会被重复读取覆盖，保存与发布仍由服务器校验。

`/workspace/blog` 和 `/admin` 使用独立入口提前加载各自专用样式，并复用原路由的权限、数据与 metadata 逻辑。公共页面仍不加载编辑器或后台专用样式。

本地冷导航采样中，编辑器 CLS 从约 **0.365 降到低于 0.001**，后台首页从约 **0.568 降到 0**。这是本地实验样本，不能视为线上用户的 p75 Core Web Vitals。编辑器网络记录中 `/api/spaces/mine` 的重复请求数为 0。

- 六个主要页面没有捕获到未处理运行错误。12 个博客预览加载完成，卡片聚焦与返回、三个资源标签的客户端转场、首页章节切换正常。

## 追加：全站指针反馈与剩余性能问题

本次将原先只在首页操作控件附近出现的量子点阵，扩展为全站鼠标移动反馈。移动区域仍为原来的 240 × 240 CSS 像素，点击操作控件时在独立的 640 × 640 局部画布中向外传播；移动指针不会带走点击原点。根布局仅挂载一个实例，客户端切页时保留反馈，博客 iframe 不初始化第二套效果。键盘激活以控件中心为原点；触摸移动不产生追随效果；减少动态时只保留短暂的局部点击提示。没有引入新依赖，静止、窗口失焦和隐藏页面停止绘制。

### 按需数据与分页

博客编辑器的 SSR 只预载账号及空间，不携带未使用的社区投稿全文。其他工作区页面也按实际用途预载，客户端同步取消无用请求。社区查询在 SQL 中完成作者资格、冻结、有效转发、关注、成员、分类、搜索、排序和分页，仅为当前页 12 篇内容读取完整正文；保留原 Unicode 小写与字面搜索语义，不缓存权限结果。

在临时数据库中，两位合格作者各 500 篇，每篇正文 10,000 个 ASCII 字节，草稿和公开版各一份：

| 测量 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 社区首批 12 条的中位处理耗时 | 59.10 ms | 8.08 ms |
| `DatabaseSync.prepare` 调用次数 | 5,005 | 66 |
| 编辑器 seed JSON 的 UTF-8 大小 | 10,297,065 B | 4,722 B |
| seed 生成耗时 | 84.88 ms | 3.82 ms |

这是本地合成数据测试；`prepare` 次数不是独立 SQL 执行数，JSON 大小不是压缩后的网络传输量，也不是当前真实账号的响应大小。

### 样式、博客预览与封面

按页面分组在服务端加载样式，原 catch-all 的请求、权限和 metadata 逻辑集中复用。保留原样式的相对顺序，启用 Next 的严格 CSS 合并顺序，防止构建工具重排后旧标题样式覆盖最终样式。首页仍为原来的桌面 32px 标题与一屏高度，手机沿用原响应式尺寸。

同一本地生产服务、中文、1440 × 1000 视口、禁用浏览器缓存的 Resource Timing 样本：

| 页面 | 解压后 CSS：前 → 后 |
| --- | ---: |
| 首页 | 780.1 → 423.8 KB |
| 资源 | 780.1 → 543.6 KB |
| 社区 | 781.5 → 451.3 KB |
| 博客空间 | 780.1 → 401.7 KB |
| 博客编辑器 | 854.8 → 697.6 KB |

以上不是网络传输量或加载提速百分比。首次 CSS 在服务器页面入口加载，编辑器与后台保留专用样式的首次布局保障。

展廊保留原有模板、12 张空间卡片、相机、聚焦、返回与键盘操作。主题 iframe 使用直接可见的服务端模板，禁止脚本执行，减少重复水合及组件初始化；真实用户上传的静态网站仍保留原脚本能力。预览类型只取已发布版本，草稿不能改变公开展示。禁脚本不等同于浏览器零脚本请求，不能将共享缓存资源按 frame 数简单累加为网络流量。

真实主题的只读预览独立于普通页面的路由图，旧 `?embed=gallery` 链接仍兼容。完整博客保留原来的按需主题边界，避免为了展廊预览让首页和资源页提前加载整个模板渲染器。新入口继续使用公开主页的资格与冻结检查，只为精确的预览路径允许同源嵌入。

全景主题默认封面由 3,113,428 B PNG 改为同尺寸 393,526 B WebP，缩略图另用 37,734 B 的 480px WebP。保留原 PNG 供既有链接使用，仅更换实际展示资源；用户上传封面不受影响。

### 异步密码派生

HTTP 登录、注册、改密、注销、邮箱绑定与找回，以及创建工具凭据，使用原生异步 scrypt。保持 v2 与旧密码格式、原参数、恒定时间比较和限流。耗时运算在 SQLite 事务外，提交前重新核对密码、会话、站长身份及其他原有条件，防止等待期间重置、注销或权限变更后旧操作继续生效。初始化脚本和兼容同步调用保留原辅助函数。

同机 5 次局部采样的中位数：密码校验总耗时约 112.8 ms 不变；0ms 定时器被延迟的时间从约 112.83 ms 降到 1.22 ms。此改动减少请求线程阻塞，不能称为密码计算本身更快。

## 追加：页面切换连续性

- 点阵背景移为根布局中的单个持久实例。资源、社区、博客目录、文档和 Skill 之间切换只重新绑定当前页面与滚动状态，复用画布、上下文、着色器和缓冲；非阅读路由隐藏并停帧，首页、作者主页、展示样例及 iframe 不初始化该阅读引擎。临时的首页暂停操作不影响随后进入的阅读背景，减少动态设置继续全站生效。
- 顶部四个公共导航在悬停、键盘聚焦和触摸意图时调用 Next 的公开预取 API。最多四个目的地、30 秒内去重，遵守节省流量与慢网设置，不预取账号、下载或全部博客预览，也不拦截点击和未保存草稿确认。
- 内容离场反馈为 120ms、保持 90% 不透明度；到达为 220–280ms 的短位移和淡入。修正博客标题接收动画的选择器，保持 3D 舞台及背景坐标不动。用户拒绝离开脏稿时立即清除离场状态与待交接记录。
- Skill 安装命令的样式由实际组件加载，移出旧首页样式，修复独立 Skill 页缺失样式时长命令撑宽手机页面的问题。命令保留完整内容并在代码框内横向滚动。

Ego 的实际导航检查中，资源 → 社区 → 博客目录 → 资源保留同一个背景 canvas，每次切页新增的阅读背景着色器编译由 **2 次降为 0 次**；返回首页后再进入阅读页也复用原实例。桌面画面与原有字号保持一致，390px 的资源及 Skill 页面没有页面横向溢出；减少动态、返回导航与移动菜单关闭均正常。以可用网络条件模拟键盘聚焦时，目标 RSC 请求在点击前发出，当前页面保持可读。

本轮 `npm test` 432 项、类型检查与生产构建通过；首页/托管、资源目录、博客编辑器 HTTP 验收通过，测试使用独立临时数据。浏览器后台节流影响了部分动画帧采样，因此不使用这些样本声称 FPS 或整体切页提速百分比。
