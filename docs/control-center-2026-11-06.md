# 控制中心与页内社区管理

模式为 Operate，延续现有后台功能与站内字体，使用紧凑的中性工作区、透明工具外壳、清晰表单和状态色。

- 侧栏按工作台、内容与页面、系统分组；减少重复的账号和退出入口。桌面保留固定导航，手机使用原生 dialog 抽屉，支持 Escape、焦点恢复与点击栏目后收起。
- 概览先展示关键统计和待办，再展示账号、内容与服务状态。详细访问报表通过原生 details 展开；选择日期范围后自动展开，原有查询及图表仍可用。
- 站长的社区概览、投稿、评论、主页、共享内容、工单、成员及治理记录共用控制中心内容区。普通点击更新页内状态，保留同一个后台外壳与当前地址。现有独立链接及修饰键打开新标签仍可用；刷新按原 URL 恢复。
- 嵌入视图继续检查现有身份、角色、账号状态和社区开放配置。审核员保留独立的社区工作区，不读取站长 bootstrap；SSR 仅为站长的社区深链预载站长外壳数据。
- 网站设置整理为页面与分享、桌面应用下载、登录与安全三组。分组切换保留表单状态；公开设置、邮箱及密码分别提交，保存和上传状态继续生效。没有增加未被网站消费的设置字段。
- 修复把修改改回原值后仍残留本地草稿的问题，避免刷新时恢复已经撤销的设置。导航继续经过现有未保存提示。
- 社区链接在 React 捕获阶段先经过共享的可取消未保存检查，再切换内容，保留正常的外链、下载、公开社区、未知路径和查询链接；取消通用页面离场反馈，避免后台停在等待跳转状态。
- 控制中心停用展示页的鼠标粒子，保留网站其他位置的效果。样式限定在 data-admin-layout="control-center"，原生滚动与博客编辑器不变。

新增测试覆盖页内链接范围、嵌入结构、表单分组、草稿撤销和角色预载边界。535 项单元测试、TypeScript、生产构建及使用隔离数据目录的社区 HTTP 集成通过。

浏览器首轮验证覆盖 1600px 桌面和 390px 手机：社区栏目和待办点击保留同一 DOM 外壳与地址；设置分组保留输入、改回原值恢复保存状态；手机抽屉可打开、Escape 关闭及选择栏目后关闭。概览页面从约 2913px 收为 1357px，高度随真实内容变化。没有提交真实网站设置、密码或审核决定；截图与浏览器记录仅存放于 /tmp。

补充验收通过：取消未保存的页内导航会留在设置页并保留输入；还原后本地草稿清除，刷新不会恢复测试修改。社区独立深链保持单一后台外壳；手机三个设置分组均完整可见，抽屉焦点和关闭行为正常；深色输入框和导航使用对应中性表面。
