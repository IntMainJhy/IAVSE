# 首页点击反馈与页面衔接

本轮基于 `a891dec`，修复首页进入其他主导航页面时波纹缺失、背景直接跳变的问题，保留页面字号、布局、玻璃场景及原有点阵几何。

## 改动

- 点击当次事件内立即绘制波纹。随后按可见帧推进，单次延迟最多推进 48ms，避免路由工作阻塞超过原有 760ms 时，第一帧直接被判定为结束。正常 60/120Hz 下仍为 760ms；减少动态效果时仍为局部 180ms 反馈。页面隐藏、失焦、卸载时清理。
- 波纹随当前页面表面切换深浅墨色，切页期间保留独立画布和真实向外移动的点，不使用缩放图片替代。仍限定为 640px、DPR 上限 1.5，每帧最多 16 批绘制；指针仍为 240px。
- 首页、社区、博客空间、资源之间的顶栏导航，使用原生 View Transition 对背景及内容做 240ms 交叉淡化。新页面实际 DOM 提交后才释放更新回调；波纹独立于页面快照，继续显示在上层。参考 [MDN：新视图是实时呈现](https://developer.mozilla.org/en-US/docs/Web/CSS/::view-transition-new)。
- 原生转场期间避免重复的 GSAP 入场。没有 API 或开启系统减少动态效果时，保留既有导航与相应的简化反馈。目录筛选、编辑器和其他链接继续使用原有处理。
- 点击接管位于锚点目标阶段，晚于所有 document capture 草稿保护、早于 Next Link 默认处理。残留目标监听器在下一任务清除：原生输入会在监听器之间执行微任务，不能用微任务提前删除目标监听器。
- 转场等待上限 1600ms；超时跳过快照并保证路由仍执行一次。连续点击、后退、取消导航、偏好变化、卸载均释放观察器、计时器及转场标记。

## 验证

- 单元回归覆盖：点击立即绘制、连续 1200ms 延迟帧、切页换色、60/120Hz 完整波纹、减少动态效果、真实草稿守卫事件顺序、连续点击、未提交/错误响应超时及原生 API 失败。
- 462 项测试、TypeScript 检查及生产构建通过；首页与资源 HTTP 集成测试使用临时数据目录通过。
- Ego 生产页面验证：首页进入资源时，点击事件即产生绘制；新页面仍有波纹，墨色由 `#aed3ff` 切换为 `#3e7cd2`。原生根视图确实运行 240ms CSS 动画，未叠加 GSAP 入场，无运行时错误。
- 390px 手机宽度无横向溢出，选中入口后菜单关闭；系统减少动态效果时正常切页且不启动整屏转场；模拟 document capture 拒绝导航后页面保持原位，清除 busy/转场标记，随后可进入博客空间。
- 自动化环境中出现约 1 秒的帧调度间隔，因此不据此宣称实际帧率。检查过渡中间画面时临时延长验收页的超时并暂停 CSS 动画；生产代码仍保留 1600ms 上限，验收后刷新恢复。

## 博客空间预加载

- 导航意图触发时，除 Next 路由外，提前准备当前展廊的公开主题文档和共用样式；省流量及慢网偏好继续跳过可选预加载。首页不挂载隐藏 iframe。
- 两路文档请求队列复用进行中的工作，当前展示优先。按语言隔离的浏览器内存缓存保留 30 秒、最多 24 份，每份原始文档不超过 350KB；不使用持久化缓存，HTTP 响应继续 `private, no-store`。清单复用 `publicSpaces` 的公开、可发现和审核边界，最多返回当前 12 个展位。
- 主题预览使用准备好的 `srcDoc`，移除 Next 水合脚本及脚本预加载；继续使用原有只读 sandbox。用户上传的静态站点保持原来的真实 URL 和脚本权限，不进入文档缓存。
- 预览文档及字体全部就绪后，整个 3D 场景统一显现，停止逐张展示身份占位内容。淡入作用于透视容器，保留内部 `preserve-3d`；镜头、卡片尺寸与选择动效不变。单个失败文档不阻塞永久显示，减少动态效果偏好关闭入场动画。
- Ego 验证：点击前已有 12 个文档请求完成，首页隐藏 iframe 为 0；进入后有 12 个完整预览、字体全部就绪、预览内脚本为 0，显示标记仅在 `loaded=12` 后切换。一次本机预加载进入的准备阶段约 355ms；390px 手机直接进入约 1.2 秒，期间统一显示准备提示，无横向溢出。
- 手机连续两次进入后，文档请求总数仍为 12，完整预览仍为 12；聚焦作者、Escape 返回概览、手机菜单收起正常。上述时长仅为本机样本，不代表其他网络环境。
- 回归覆盖两路并发、任务去重与优先级、缓存到期与容量、语言隔离、失败降级、字体就绪及卸载、上传站点权限和公开清单边界。生产构建、类型检查、首页 HTTP 集成验证通过。
