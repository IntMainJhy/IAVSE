覆盖首页、博客空间、资源、社区、博客编辑器及管理后台的共享加载链与数据读取。保持已有视觉、3D 卡片布局、聚焦动画和发布流程。

## 改动

- 编辑器、React Flow 和后台的专用样式随对应组件加载，公共页面不再携带这些样式。
- 博客行内富文本编辑器在点击文字编辑时加载；管理后台正文编辑器在打开内容编辑页时加载。加载期间保留原文字或现有加载提示。
- 英文、日文词库分开加载；中文不下载翻译词库。服务端与客户端共用翻译规则，语言切换使用 React transition 保持当前界面可用。日期格式化独立于词库，并复用最多六种语言/时间格式的 `Intl.DateTimeFormat`。
- Inter、Geist Mono、Cormorant Garamond 使用保留字形及可变轴的 WOFF2 文件：总计 **2,244,084 → 631,304 字节，减少 71.9%**。原 TTF 与各自 OFL 许可保留；字体只在实际使用时下载。
- 仅为随站字体、品牌、展示头像、模型和首页媒体设置一天公共缓存及七天 stale-while-revalidate。账号 API 和用户上传媒体继续使用原有访问检查及禁止缓存策略。
- 共享资源在 SQL 中先按分类筛选，再应用 1,000 条上限。列表查询只选择公开字段，使用 JOIN 获取作者名称，并在一次请求内读取站长信息，避免逐条查询。列表显式选择摘要模式时，不从 SQLite 返回完整正文；详情与既有 API 默认完整内容保持一致。
- 博客公开文档的投诉冻结检查合并进 SQL，避免对每条文档单独查询；整站及单条冻结边界保持一致。

## 验证

- `npm test`：388 项通过；增加了分类上限、摘要/正文一致性、按语言加载词库及静态缓存范围回归检查。
- `npm run typecheck`、`npm run build` 通过。
- `npm run test:homepage:http`、`npm run test:catalog:http`、`npm run test:blog-editor:http` 在独立临时数据库上通过。
- 浏览器验证六个主要页面无未处理运行错误；中英日切换、文字编辑工具栏按需出现、后台正文编辑器按需打开正常。未保存或发布验收用内容。
- 资源三个标签的客户端转场、12 个博客预览加载、卡片聚焦与返回正常。
- 390px 视口下文档与博客页均无横向溢出。系统减少动态效果模式下，博客浮动动画为 `none`，背景在稳定采样中没有连续 WebGL 绘制。
- 实际 HTTP 验证 WOFF2 返回公共缓存策略，账号 API 和不存在的用户媒体仍返回 `no-store`。

## 维护

翻译内容分别维护在 `src/lib/locales/en.json` 与 `ja.json`；测试检查两份词库键一致、占位符一致，并逐项比对客户端与服务端翻译。日期展示组件应使用 `locale-format.mjs`，客户端翻译由 `LocaleProvider` 提供，避免重新引入两份完整词库。

未哈希命名的随站资源采用一天缓存；内容更换且需要即时生效时更新资源路径。真实用户数据、权限判定和下架结果不做跨请求共享缓存。
