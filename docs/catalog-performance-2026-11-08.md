# 开源模板扩充与目录性能（2026-11-08）

本轮新增 6 套直接来自原维护者的 MIT 项目：AdminKit 免费版、Agency、Starlight、Nextra、Jekyll Theme Console、Hugo Blog Awesome。现在共 72 项：18 个完整网站项目、54 个品牌设计规范。模板不是同一布局换色；分别采用后台侧栏、机构展示、多级文档、MDX 内容站、终端博客、轻量文章索引。

每项保留原作者、仓库、固定提交、原始文件、完整 MIT、实际演示与本站编写的设计说明、组件提示词。逐项记录见 [许可与文件证据](open-template-expansion-2026-11-08.json)，封面追溯见 `public/template-covers/project-covers.sources.json`。6 套均在本站隔离 iframe 实际打开并读到真实内容。AdminKit 使用 `demo-mit.adminkit.io`，不指向付费版。封面移除示例位图照片、头像与 URL 背景图片，Agency 以中性色替代被省略的照片背景，保留其布局和文字层级。

## 已完成的改动

- 资源分类、目录详情与分页链接关闭自动预取，只有实际导航才加载相应目录。基线浏览器会预取 UI 与 Skill 两个 RSC 响应，合计约 282 KB 解码数据；修改后这两个目录预取消失。主导航的小型预取不在本次关停范围。
- 目录筛选构建一次文本与分类索引，搜索、收藏和排序复用，分类计数也从索引读取，避免一次交互反复扫描和规范化同一批字段。目录快照变化会重建索引，旧快照不能隐藏新条目。
- 列表只传递显示、过滤和预览所需元数据。完整规范和长提示词只由详情读取。SQLite 公共目录与公开 slug 查询增加索引；详情直接查单条记录，不再读取所有完整文档后查找。
- Skill 目录使用 React 请求内缓存，供同次服务端渲染及 metadata 复用；没有跨请求缓存审核状态。下一次请求继续读取撤回与可见性状态。
- 72 张封面预生成不超过 480px 的 WebP，通过 srcset 供普通密度屏幕选用，较高密度屏幕可选原图；展开预览保留原始图。缩略图附有原图及派生文件 SHA-256。新增模板继续沿用一次 24 项的连续加载、离屏内容隔离及点击时才挂载的单个 iframe。
- Nginx 单站及分域部署示例增加仅限 `/_next/static/` 的磁盘缓存、并发回源锁和文本压缩。保留上游 Cache-Control、Vary、Set-Cookie 规则。HTML、RSC、账号、API、用户文件不进入这个共享缓存。配置依据 [Nginx proxy 文档](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_cache) 与 [gzip 文档](https://nginx.org/en/docs/http/ngx_http_gzip_module.html)。这只是部署示例，本次未修改线上 Nginx；启用前创建缓存目录并按实际 Nginx worker 用户授权，执行 `nginx -t` 后再平滑重载。

## 继续增长时的边界

现在 UI 首次 DOM 限制为 24 张卡片，完整规范不随列表传输，但用于本地筛选的摘要元数据仍会随目录总量增长。达到数千项时，下一步应把筛选、分类统计和游标批次放到服务端，继续呈现向下自动追加的单页浏览；需要一并验证收藏、历史返回和审核撤回。当前实现没有假称元数据已完全按批次传输。

数据库已有 WAL、busy timeout、事务与审核边界；这次补充公开读取索引。SQLite 写入依然有单写者限制，不适合把数据库文件复制到多机后各自写入。扩展到多实例前需共享数据库/迁移 PostgreSQL、对象存储与上传访问控制、集中限流、后台任务与会话一致性。静态构建文件可走 CDN，带账号或 nonce 的页面不直接套用公共缓存。

正式扩容应在目标硬件和数据库副本上，混合测试匿名浏览、登录、发帖、审核、图片上传、搜索和第三方演示失败；监测 P95/P99、错误率、CPU、内存、数据库等待、磁盘和备份恢复。用这些结果决定实例数、数据库和缓存配置，不能从这次本机 10 并发推断公网容量。
