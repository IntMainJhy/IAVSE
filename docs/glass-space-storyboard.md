# IAVSE 品牌与空间设计

2026-11-01。品牌名由用户确定为 **IAVSE**，五个核心理念为 **INSIGHT · ARTIFICIAL INTELLIGENCE · VIGILANCE · SEIZE · EVOLVE**。品牌宣传语为 **Insight through AI. Vigilance for Opportunity. Seize to Evolve.**，中文为 **以洞察驱动智能，以敏锐发现机遇，以行动实现进化。** 历史链接、工具配置、资源标识与作者发布内容保留兼容。

## 当前阶段

用户已确认深蓝到银白、近乎隐形的透明曲面与真实产品窗口的视觉方向。新向量图标已从旧 Folivo 小写 f 更换为“开放视口”；空间模型、相机与页面实现按阶段检查。下述分镜描述目标，不应仅凭文档视为所有效果已验收上线。

图标用两个实心斜切折面组成开放的 V 形轮廓，中间 8 单位的负形竖缝呼应 I，在 16px favicon 中保留 2px 间隙。导航透明符号、SVG 浏览器图标、16/32/48px ICO、180px Apple 图标与 512px PNG 从同一向量源生成；小尺寸不采用玻璃、细线、渐变或五个微型字母。

## 已确认方向：连续的光学界面

一张大尺度、平缓、非对称的透明曲面延伸到画外，只用少量局部边缘反光和背景折射显示深度。深蓝上层、中蓝空间与银白下层连续过渡；清晰的文字和真实产品窗口是阅读重心。不是将 Logo 放大成厚重中心雕塑，不使用陈列台、镜面地板、空中光束或发光圆环。

模型形态、材质和镜头在浏览器中逐项检查。新场景复用已有 Next.js、React、TypeScript、Three.js、React Three Fiber 与 GSAP。HTML 文字与可操作组件保留语义；背景由单一主场景承担，弱设备、减少动态效果和 WebGL 失败时仍可阅读及操作。图标与空间共享几何语言，不在 favicon 中模拟透明材质。

## 本轮实现

- `scripts/build-iavse-surface.py` 在 Blender 中构建封闭的非对称弯月透镜，前后面使用不同曲率，边缘厚度约 .075，中央逐渐加厚至约 .715。中央面与抛光倒角属于同一封闭体，使用 IOR 1.46/1.50 的透明材质；没有另画空中发光线。桌面 GLB 891,684 字节、46,638 三角形；手机 GLB 265,344 字节、13,482 三角形。
- `src/lib/home-glass.ts` 加载模型并生成画外摄影棚环境。柔光箱只用于环境贴图，带横向亮度变化的深蓝到银白背景提供折射参照。材质环境旋转随时间更新，镜头推进与模型基准缩放解耦；鼠标改变曲面角度，滚动将同一曲面连接到下方各个镜头。此处使用实时光栅透射与色散近似，不宣称光线追踪。
- 光学镀层通过同一模型的局部位置、表面法线和视角实时计算银蓝高光、局部色彩与柔和天空反射；它是物理透射之外的艺术化着色，不是贴在屏幕上的图片或线条。时间、退场透明度与减少动态设置同时控制材质和镀层。手机使用更宽的场景裁切，保持曲面形状。
- 日光环境只在画外捕获：带云层亮度变化的天空与高动态范围太阳共同进入反射贴图，柔光窗使用透明羽化边缘。曲面上的锐利日光高光与环境中的太阳共享方向，并沿实际边界移动；局部 RGB 光谱峰错位表现棱边色散，不给整个模型添加虹彩。主体粗糙度 .014、边缘 .010，原生色散为主体 .26/边缘 .8。首屏透射缓冲边长保留桌面 90%/手机 70%，清晰呈现曲面内外的亮度差和边缘折射。
- `HomeCinema` 提供实际加载进度、背景暂停、减少动态效果与返回顶部重播。GSAP ScrollTrigger 将标题轻移和产品窗口接近关联到同一段原生滚动；组件离开时清理时间轴，重播不重置画布编辑状态。
- `iavse-home.css` 统一首屏排版、白色按钮、透明导航和产品窗口的银白底色。首个窗口继续显示审核通过的真实公开博客；下方交错模块保留可编辑画布、Skill 视频与资源交互。
- 减少动态效果以系统设置为优先，手动设置保存在本地；隐藏、离屏和打印时停帧。结束镜头在页面实际可达的滚动终点前淡出并停帧。WebGL 加载失败使用 CSS 渐变，HTML 内容和操作仍可使用。

### 连续滚动镜头与预算

`V2Atmosphere` 在布局变化后测量真实模块的位置，把归一化章节传给同一个主 WebGL 场景。滚动帧只读取滚动值，不反复查询元素或测量边界；图片、字体、尺寸和 ScrollTrigger 刷新才使布局缓存失效。镜头正反向均由滚动位置决定，不劫持滚轮。

| 章节 | 连续镜头 | 内容交互 |
| --- | --- | --- |
| 博客 | 首屏曲面缩小，转到内容右侧，镜头小幅侧移 | 真实公开主页截图与链接 |
| 画布 | 曲面转向左侧，局部日光反射随视角变化 | macOS 窗口正视；编辑、拖动、撤销、预览保留真实坐标 |
| Skill | 镜头轻微推进，曲面翻到右侧 | 真实界面视频按可见性播放，可暂停 |
| 资源 | 背景停靠并停帧，场内模型接管运动 | R3F 模型旋转、拖动与悬浮 |
| 结束 | 同一曲面回到中央、拉远、淡出 | 品牌入口与返回顶部重播；向上滚动自然恢复 |

桌面较高视口给每段 138svh 的阅读停留，图片和文案以 GSAP 的接近、停留、离开时间轴衔接；真实编辑器与资源画布只调节淡入和边缘焦点，不施加倾斜变换。手机、矮屏保留自然文档流；减少动态时撤销滚动动效和长段停留。

首屏总像素预算桌面 800 万、手机 300 万，DPR 上限 2/1.5；阅读镜头 DPR 上限 1.25/1，透射边长比例 .5/.35。连续渲染的持续延迟会降低像素密度，稳定后逐级恢复；不以偶发的短帧间隔判断显示刷新率。主模型、环境贴图和渲染器全程复用；粒子仅为 64/28 个缓冲顶点。透明淡出和实体着色程序异步预热，避免首次退场临时编译。

资源模型与视频仅在接近视口且允许动态时加载。首次就选择减少动态的访问只显示海报，不初始化卡片模型或视频解码器；之后切换设置复用已有实例。暂停、重播、系统设置和打印统一控制背景与卡片，重播保留画布中的编辑结果。以上预算是设备适配策略，不承诺所有设备固定帧率。

重新导出模型（Blender 5.x）：

```sh
blender -b -t 1 -P scripts/build-iavse-surface.py
# 可选：在版本库外另存可编辑 Blender 工程
blender -b -t 1 -P scripts/build-iavse-surface.py -- --blend-output /absolute/path/iavse-optical-surface.blend
```

网站启动、生产构建与部署仍使用项目 README 中的原有流程，无新增运行依赖。

光学回归测试同时检查导出模型的真实曲率、渐变厚度、法线和封闭拓扑，以及实际顶点投影在镜头推进前后的变化。测试还验证所有显式环境贴图随摄影棚旋转、自定义镀层共享时钟、减少动态和退场时停止着色运动。最终外观与运动需在实页中观察，加载成功或参数测试通过不能代替视觉检查。

# IAVSE 玻璃空间分镜与页面关系

2026-10-31，基于已有蓝色原生玻璃世界扩展公共平台。网站使用一个明亮的玻璃外观，移除平台深色/跟随系统开关；作者自己选择的博客主题、字体与页面几何仍独立保存。

## 首页

| 滚动位置 | 镜头和模型 | 内容 |
| --- | --- | --- |
| 0–0.2屏 | 原生双折面玻璃围住首屏，鼠标轻微环视 | 居中介绍和实际入口 |
| 0.2–1.3屏 | 玻璃缩小、后退、合拢并上收 | 展板由玻璃薄片弯曲展开衔接 |
| 1.3屏以后 | 小型玻璃标记停在导航空隙 | 作品和创作者列表沿连续冰蓝背景进入 |

展开效果由同一Three.js画布中的真实分段曲面完成，最多同时两块；正文保持正常HTML，使用同一个滚动进度轻微展开，不将正文变成低分辨率图片。导航固定在窗口顶部，背景模糊通过渐变遮罩逐渐减弱，不切成一块白底。收拢完成后，同一个画布接到内容上层，玻璃后方的接收面只在最终画面透明；透射采样仍保留摄影棚。小型原生玻璃标记约48px高，停靠在品牌与导航操作之间的实测空隙；最终透明度0.55，叠在导航模糊层上方保持清晰，避免覆盖作品。内容和后续展开曲面仍清晰可见，不增加第二个渲染器。

## 博客空间

`/blogs`现在是公开空间目录，有独立标题和canonical；不再根据登录者或默认作者替换整页。原有`/blog/:handle`永久地址、公开资格、审核快照、静态网站沙箱和分享规则保留。

分镜为：远处玻璃页面进入 → 镜头穿过页面 → 页面从两侧掠过 → 到达完整空间目录。原生滚动驱动镜头，可以直接跳过进入目录，也可点击当前玻璃打开对应博客。场景取前8个符合公开条件的空间作飞行预览，全部可发现空间仍以可访问HTML目录列出。

模型由已安装Blender原生生成：`scripts/build-blog-glass.py`产生带真实厚度、0.10倒角、8段细分和法线的玻璃页面（保留0.04侧边，避免倒角薄面重叠），导出`public/models/spaceyew-blog-panel.glb`。可编辑`.blend`源在网站Git之外的本地设计档案保留。页面正面的高分辨率显示层包含真实公开名字、简介、头像与封面，直接输出清晰内容；原生玻璃使用正面渲染，避免双面背部进入透射缓冲；圆角由真实几何与MSAA抗锯齿形成，取消透明贴图裁切造成的虚线。边缘独立保留透射、反射与色散，避免正文经过低分辨率透射缓冲和物理材质的mip滤波后变糊。不加载私有草稿，不执行嵌套博客iframe。恢复原有5控制点摄影棚光线，并加上画外延长端点，避免光线在视口内突然截断；放在全部页面后方，并按页面数量保持开场比例。飞行画布从视口顶部铺满到透明导航后方，导航高度只参与保持原有镜头时序，不再形成顶端画面接缝。

## 导航与资源

公共导航为：首页、社区、博客空间、资源。资源中心通过分类切换文档、Skill及其他资源；已有`/docs`、`/skills`及详情/投稿地址保持有效，顶栏统一选中“资源”。社区与编辑器使用同一玻璃色彩、薄片层级和导航语言，现有关注、收藏、投稿、审核、保存、发布等接口不变。

## 动态与性能边界

首页、博客空间入口、其他平台页面各使用自己的单个WebGL画布，不重复叠加背景渲染器。原生滚动保留，不拦截滚轮。博客飞行以120Hz及以上为目标，交互时跟随requestAnimationFrame与显示刷新率，不再限制30fps；主画布采用桌面300万、手机150万像素预算，DPR最多2，保留原始内容贴图与MSAA。玻璃透射源保留桌面70%、手机55%的边长分辨率；固定Three.js r187的基底LOD采样与自动mipmap关闭成对启用，避免逐帧生成未使用的整条mipmap，保留原生反射与RGB色散。静止时停止请求帧，隐藏、离屏和打印时暂停；减少动态效果时提供静态主体和可访问内容，WebGL失败仍可浏览目录与操作页面。玻璃使用Three.js RGB色散近似，接收面的焦散是艺术化近似；不宣称完整光线追踪或所有设备的固定帧率。
