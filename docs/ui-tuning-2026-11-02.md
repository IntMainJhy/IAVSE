# IAVSE 首页与资源转场调整

本轮以 `17c47d3` 为基线，已核对本地 `main`、GitHub `main`、AtomGit `main` 与实际运行的 IAVSE 源码一致。早期 `design/ui-v2` 上的尝试只做本地归档，不纳入本轮提交。

## 设计方向

保留 IAVSE 的弧形光学玻璃、品牌文案、本地字体、首页演示和现有栏目。首页用更深的海军蓝与钴蓝建立纵深，再平缓过渡到浅色阅读面；玻璃的反射、透射与实际背景使用相同色阶。

首屏只保留一个 macOS 下载入口，使用苹果标识、半透明渐变、内侧高光和细边缘。沿用站点已配置的 macOS 安装包 HTTPS 地址；未配置时进入 `/downloads#download-macos`，不创建安装包或虚构可下载版本。下方的创建空间入口继续保留。

## 资源切换

资源标签预取完整目标页面，切换标签保留滚动位置。资源内容增加短距离的方向性离场与入场，导航和背景保持原位；不等待动画结束才开始导航。保留社区原有布局衔接，处理连续点击、前进后退、减少动态效果和导航失败后的样式恢复。

新版内页已使用独立的轻量量子背景，本轮没有套用旧版玻璃背景的性能补丁。

## 博客空间的隔离

多人 3D 展廊在 `design/iavse-blog-space-showcase` 独立分支开发，不合并回主版本。内置展示档案与真实账号、发布资格、社区互动及公开空间计数分离。

审查流程参考 [Unslop](https://github.com/heydamir/unslop)，作者 Damir Sokolovsky，CC BY 4.0。用户明确要求保留和调整液态玻璃与渐变，因此本轮围绕现有品牌打磨，没有整体替换主题。
