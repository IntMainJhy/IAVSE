# 全站三套 UI 切换

网站右上角“切换 UI”提供用户选定的三种样式：字符潮汐（原方向 01）、打开 IAVSE（原方向 02）、海风来信（原方向 04）。默认海风来信。普通页面、编辑器和管理后台共用同一个选择。

三套界面共享业务和真实内容，分别使用石墨色与等宽标签、明亮白色与立体字标、海边暮色与衬线标题。背景、文字、卡片、表单、按钮、边框、导航及平台弹层随选择同步变化。资源、社区、文档、博客目录、登录、账号、编辑器、管理、关于、法律和下载页面均接入。

首页保留完整动态场景；阅读页面使用弱化后的背景，保证内容清晰。字符与动漫场景按需加载，离开开头视口或页面隐藏时暂停；品牌页面使用同场景字标静帧。减少动态偏好、场景故障回退及切换销毁沿用首页机制。

根布局的 provider 同步 `data-site-style`、兼容属性 `data-home-style` 和原有明暗属性。选择即时生效并保存到 `iavse-home-style` 偏好 cookie，有效期一年；服务端校验后在首次响应中恢复。跨页、浏览器返回和刷新保持选择。浏览器禁止保存时仍可临时切换，并通过状态消息说明保存失败。`site-color-mode` 同步写入，仅用于兼容旧控件，不再独立决定全站外观。

普通页面在共享导航右侧提供切换入口；博客和工具页面在自身平台工具栏提供入口。编辑器菜单高于画布，管理页菜单使用独立的可读配色。手机端直接提供切换按钮，保留语言、账号和底部导航。菜单支持方向键、Home/End、Enter、Escape及焦点返回，导航后自动关闭。

全站样式止于作者作品、富文本正文、画布和模板 iframe 的内容边界。平台导航、编辑工具和预览工具栏参与切换；成员保存的设计与第三方模板保留原有外观，切换界面不修改内容或草稿。

滚动增强的临时状态保存在 DOM 节点属性中，不再向尚未水合的流式 React 内容添加 HTML 属性，避免社区页面的水合不一致；离场重播、焦点可见和减少动态行为保持有效。

验证：TypeScript 检查及 76 项相关测试通过；本地 HTTP 检查覆盖 15 条路由 × 3 套样式、非法偏好回退和权限隔离。真实浏览器检查桌面与手机、跨页和刷新保留、编辑器菜单、管理页、已加载的资源预览工具栏。三套社区界面在 1440×900 和 390×844 的六张最终截图中未发现溢出、图片失败或水合问题。独立视觉和 UX 检查发现的菜单与预览工具栏可读性问题已修复并复看。
