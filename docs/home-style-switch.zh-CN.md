# 首页样式切换

首页右上角“切换 UI”提供用户选定的三种样式：字符潮汐（原方向 01）、打开 IAVSE（原方向 02）、海风来信（原方向 04）。默认海风来信。

三套首屏由原生 React 组件实现，共享真实资源、社区、博客和账号入口；下方首页内容随样式调整配色。其他业务页面继续使用现有共享界面。

选择即时生效，保存到 `iavse-home-style` 偏好 cookie，有效期一年。服务端在首次响应中读取并校验，客户端由根布局中的 provider 延续，刷新和往返导航保持一致。浏览器禁止写入时仍可临时切换，并提供保存失败的辅助技术状态反馈。

每次只加载当前场景。Three.js 场景模块采用 `render/resize/dispose` 生命周期；切换时清理几何、材质、纹理和 renderer。暂停、页面隐藏和场景离开视口时停止渲染。尊重系统减少动态偏好。字符与字标场景失败时显示同场景静帧；动漫保留原创插画、光点和鼠标视差，可切换日落/暮色。

菜单支持鼠标、触摸、方向键、Home/End、Enter、Escape及焦点返回。手机端直接提供切换入口，保留原有更多设置与底部导航。

验证：相关首页、内容、滚动、导航测试31项及TypeScript检查通过；实际浏览器覆盖三样式桌面/手机、刷新保留、键盘、保存被拒、减少动态和WebGL丢失回退。独立视觉评审8/10，已修复手机说明断行；独立UX走查完成外观切换/刷新/手机往返路径，无关键障碍。视觉余量主要是手机立体字标的比例细化与下方内容的进一步编排。
