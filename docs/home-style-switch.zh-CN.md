# 全站四套 UI 切换

网站右上角“切换 UI”提供四种样式：字符潮汐（原方向 01）、打开 IAVSE（原方向 02）、海风来信（原方向 04）、经典原版（`main` 的原有 UI）。无有效偏好时使用经典原版，已有三套偏好继续保留。普通页面、编辑器和管理后台共用同一个选择。

四套界面共享业务和真实内容。前三套分别使用石墨色与等宽标签、明亮白色与立体字标、海边暮色与衬线标题；经典原版恢复 `main@97871e0` 的居中首屏、社区／资源双入口、流动雾光与浅／深色配色。背景、文字、卡片、表单、按钮、边框、导航及平台弹层随选择同步变化。资源、社区、文档、博客目录、登录、账号、编辑器、管理、关于、法律和下载页面均接入。

首页保留完整动态场景，经典原版的着色器独立按需加载。功能页不再挂载动态背景组件或分配对应的画布：字符版和动漫版使用静态图，经典原版使用 CSS 柔雾，品牌版不显示装饰字标。字符与动漫首页离开开头视口或页面隐藏时暂停；减少动态偏好、场景故障回退及切换销毁沿用首页机制。

根布局的 provider 同步 `data-site-style`、兼容属性 `data-home-style` 和原有明暗属性。选择即时生效并保存到 `iavse-home-style` 偏好 cookie，有效期一年；服务端校验后在首次响应中恢复。跨页、浏览器返回和刷新保持选择。浏览器禁止保存时仍可临时切换，并通过状态消息说明保存失败。经典原版保留明暗切换与 `site-color-mode`，离开原版时通过 `iavse-classic-color-mode` 保存独立偏好，回到原版时恢复；另外三套保持各自固定配色。

普通页面在共享导航右侧提供切换入口；博客和工具页面在自身平台工具栏提供入口。编辑器菜单高于画布，管理页菜单使用独立的可读配色。手机端直接提供切换按钮，保留语言、账号和底部导航。菜单支持方向键、Home/End、Enter、Escape及焦点返回，导航后自动关闭。三套首屏均移除底部样式标识、暂停/光线操作及额外发现栏，主按钮改为纯文字；动态仍尊重系统减少动态偏好。

全站样式止于作者作品、富文本正文、画布和模板 iframe 的内容边界。平台导航、编辑工具和预览工具栏参与切换；成员保存的设计与第三方模板保留原有外观，切换界面不修改内容或草稿。

滚动增强的临时状态保存在 DOM 节点属性中，不再向尚未水合的流式 React 内容添加 HTML 属性，避免社区页面的水合不一致；离场重播、焦点可见和减少动态行为保持有效。

本轮验证：TypeScript、127 项相关测试及隔离目录中的生产构建通过；本地生产 HTTP 检查覆盖 15 条路由 × 4 套样式、原版深色、非法偏好回退和权限隔离。真实浏览器核对四项切换、跨页、刷新、原版明暗记忆、键盘循环和品牌功能页去字标；功能页四套均无背景画布。本轮为恢复既有 UI 和局部删除、性能修改，由主 Agent 查看实际截图并走查交互，未重新进行方向探索或独立视觉评审。此前三套编辑器、管理页、预览工具栏的检查仍保留原验收范围。
