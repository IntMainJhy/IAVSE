# 后台入口与布局精简

后台保留审核、成员权限、站点内容、文件、分类标签、设置、回收站和日志等实际管理操作，使用单层导航、表格与连续表单。

## 移除与合并

- 移除后台独立的“博客主页”“资料与经历”入口和旧的个人资料表单。个人博客与资料编辑统一使用 `/workspace/blog`，现有画布编辑器继续使用。
- `/admin/blog`、`/admin/profile` 作为旧地址跳转到前台编辑器。合并部署使用本站路径；独立后台使用配置的公开网站地址，避免编辑器留在后台服务。
- 共享内容审核只保留社区治理中的入口，删除侧栏重复入口和审核页内重复的返回入口。社区治理仍在当前后台页面切换。
- 项目、文章、资源合并为侧栏的“站点内容”，进入后用文字标签切换。三个内容列表、编辑、发布、下架、恢复和现有地址保留；这些内容仍用于公开项目、文章和求职页面。
- 概览删除重复的账号分布、内容分类、安装包配置状态、创建内容快捷入口及空的最近编辑模块。待办改为表格，增加真实的共享内容待审数量；详细访问数据仍可展开查询。
- 社区治理删除统计卡片与重复的审核快捷卡片，保留队列、紧急事项、运行状态开关和规则链接。
- 设置取消分类切换、重复的顶部保存按钮和只读邮箱展示。封面、简历附件、真实下载链接配置连续编辑；密码修改保持独立表单。

## 数据与兼容

本次未删除数据库记录、上传、真实资料、内容、备份或配置值。旧站点资料及相关 API 保持兼容，不再提供一套并行的资料编辑界面。文件引用保护、权限检查、未保存提醒和本地草稿保留。

布局统一去掉大圆角分类容器、阴影和卡片网格，以标题、留白与分隔线组织内容。手机端沿用可关闭的原生导航抽屉，表格与内容标签支持原生滚动。

## 验证

- 全量单元测试、类型检查、生产构建。
- 隔离数据库 HTTP 验证社区审核、权限与持久化，以及博客编辑和两种部署方式的旧地址跳转。
- 浏览器检查桌面与 390px 手机布局、社区原地切换、内容标签、设置表单、导航抽屉及溢出情况；未向真实数据提交修改。
