# 后台入口与布局精简

后台保留审核、成员权限、站点内容、文件、分类标签、设置、回收站和日志等实际管理操作，使用单层导航、表格与连续表单。

## 移除与合并

- 移除后台独立的“博客主页”“资料与经历”入口和旧的个人资料表单。个人博客与资料编辑统一使用 `/workspace/blog`，现有画布编辑器继续使用。
- `/admin/blog`、`/admin/profile` 作为旧地址跳转到前台编辑器。合并部署使用本站路径；独立后台使用配置的公开网站地址，避免编辑器留在后台服务。
- 共享内容审核只保留社区治理中的入口，删除侧栏重复入口和审核页内重复的返回入口。社区治理仍在当前后台页面切换。
- 项目、文章、资源合并为侧栏的“站点内容”，进入后用文字标签切换。三个内容列表、编辑、发布、下架、恢复和现有地址保留；这些内容仍用于公开项目、文章和求职页面。
- 概览删除重复的账号分布、内容分类、安装包配置状态、创建内容快捷入口及空的最近编辑模块。待办改为表格，增加真实的共享内容待审数量；详细访问数据仍可展开查询。
- 社区治理删除统计卡片与重复的审核快捷卡片，保留队列、紧急事项、运行状态开关和规则链接。
- 设置取消分类切换、重复的顶部保存按钮和只读邮箱展示。封面、简历附件、真实下载链接配置连续编辑；密码修改保持独立表单。

## 数据与兼容

本次未删除数据库记录、上传、真实资料、内容、备份或配置值。旧站点资料及相关 API 保持兼容，不再提供一套并行的资料编辑界面。文件引用保护、权限检查、未保存提醒和本地草稿保留。

布局统一去掉大圆角分类容器、阴影和卡片网格，以标题、留白与分隔线组织内容。手机端沿用可关闭的原生导航抽屉，表格与内容标签支持原生滚动。

## 验证

- 全量单元测试、类型检查、生产构建。
- 隔离数据库 HTTP 验证社区审核、权限与持久化，以及博客编辑和两种部署方式的旧地址跳转。
- 浏览器检查桌面与 390px 手机布局、社区原地切换、内容标签、设置表单、导航抽屉及溢出情况；未向真实数据提交修改。

## Dashboard 外观更新

按 unslop 方法整理（Damir Sokolovsky，https://heydamir.design/unslop，CC BY 4.0）：240px 左侧导航贴齐窗口边缘，64px 顶栏和统一操作按钮，石墨色明暗主题、蓝色导航标记、表格表头及数据摘要统一层级。顶部明暗按钮通过 Cookie 保存偏好，服务器首屏读取，刷新保持主题。手机端继续使用导航抽屉。验证明暗桌面截图、手机溢出及刷新后的主题持久化。

## 子功能导航与深色控件

社区治理、站点内容改为左侧可折叠子菜单，当前分组自动展开，移除内容区重复导航。手机端为贴边全高抽屉，支持原生 Escape、遮罩关闭及背景滚动锁定；社区子页面延续原地切换和未保存保护。统一编辑器、原生预览弹窗、文件控件、社区操作按钮与错误状态的深色颜色，窄屏编辑表单和操作区改为单列或换行。

## 侧栏状态与切换稳定性

所有侧栏列表入口统一在工作区切换，修复当前地址与内部社区视图不同步时无法返回原页面的问题；筛选参数在跨入口时清空。展开状态由工作区共享，桌面与手机一致，按钮控制子菜单显示，避免原生 toggle 事件与 React 状态互相回写。再次点击当前页面不重载。内容区取消整页进场动画并保留最小高度；抽屉仅在真正点击遮罩时关闭，内部留白不会误关。选中状态与悬停区分，面包屑显示具体子功能。

## 卡片式内容区

按用户最新偏好，将后台内容区改为卡片式 UI：概览的四项真实统计使用独立卡片，五项审核待办使用可点击卡片，表格、文件、审核详情与设置分区共用 16px 圆角和中性表面。桌面待办采用两张宽卡片加三张紧凑卡片，手机统计两列、待办单列，手机面板圆角为 12px。设置卡片各自按内容高度排列，文件控件保留内边距。

浅色背景与白色卡片分层，深色背景与石墨色卡片分层，不增加逐卡片进场动画。保留已有左侧导航、子功能折叠、抽屉、主题切换、权限与数据，不恢复先前删去的重复功能。概览待办仍使用真实数量，点击进入原有审核队列。

验证：536 项单元测试、类型检查、生产构建、隔离社区 HTTP 流程；浏览器确认桌面明暗概览、卡片跳转及选中状态、设置页和 390px 手机概览/设置/内容表格无整页横向溢出。
