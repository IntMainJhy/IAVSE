# Homepage artwork

- `sea-breeze.webp`: original AI-generated illustration commissioned for IAVSE's homepage in this design session. No third-party anime or gallery artwork is embedded.
- `sea-breeze-daylight.webp` and `sea-breeze-daylight-960.webp`: the current light Sea breeze artwork, generated with the built-in image generation tool on 2026-11-15 and edited to long hair at the user's request. An original fictional creator draws in a sunlit coastal studio. Both files preserve the complete 1536:1024 composition; the smaller file is resized to 960:640 for phones and static reading-page atmosphere. WebP quality 86. Prompts, tool and processing notes are in [the source record](sea-breeze-daylight.source.json). The service did not expose a model name or cost. The PNG master is retained in the local design workspace outside this public repository. The earlier sunset asset remains historical and is no longer the default scene.
- `fly-fallback-*.webp` and `git-fallback-*.webp`: stills rendered from IAVSE's own Three.js scenes. Displayed while loading or when WebGL is unavailable; desktop and mobile compositions are separate.

The referenced oil-ui gallery pages informed the visual direction. Their source, artwork and branded assets were not incorporated into the website.
