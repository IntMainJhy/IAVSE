# Homepage artwork

- `sea-breeze.webp`: original AI-generated illustration commissioned for IAVSE's homepage in this design session. No third-party anime or gallery artwork is embedded.
- `fly-fallback-*.webp` and `git-fallback-*.webp`: stills rendered from IAVSE's own Three.js scenes. Displayed while loading or when WebGL is unavailable; desktop and mobile compositions are separate.

The referenced oil-ui gallery pages informed the visual direction. Their source, artwork and branded assets were not incorporated into the website.
